## 已实现 source-specific runtime

### J4M-05 推出师法

`chushi_fa(...)` 固定四个来源条件：

- 算 12 / 22 / 32；
- 三门具；
- 五将发；
- 出军取开、休、生三吉门。

实现把前三项与实际所选出军门分栏；没有给出门时只返回 `ready_pending_gate`，不提前宣称完成出师。

明确禁止用《统宗》卷五“人君出师略地”的天子/诸侯/大夫兵额表替代。

### J4M-06 推陈兵向背

`chenbing_xiangbei(...)` 只实现正文明确的 1 / 2 / 4 / 5 / 6 / 9 六类。

不把任意 1..40 算数自动取个位，也不调用旧卷十五“陈兵出乡”。

### J4M-07 推制阵随地法

`zhizhen_suidi(...)` 固定：

- 曲阵 = 水
- 锐阵 = 火
- 直阵 = 木
- 方阵 = 金
- 圆阵 = 土

并实现正文五类地形制阵。J4M-07 仍与 J4M-08“随地制变”保持独立。

### J4M-09 推太乙在天外地内法

`taiyi_tianwai_dinei(...)` 只实现《金镜》卷四 profile：

- 8 / 3 / 4：地内助主
- 9 / 2 / 7 / 6：天外助客
- 1 宫：本段正文未列，保持 `not_defined_by_source_passage`

《统宗》卷五 `1/8/3/4` 另存 source variant，不覆盖本层。

### J4M-10 推奇伏法

`qifu_fa(...)` 将原文条件分别保存：

- 奇兵比例三成；
- 天目所临作为大煞位输入；
- 12 / 22 / 32：伏兵时；
- 11 / 21 / 31：伏藏隐迹、山林沟涧；
- 掩迫：伏兵所取时机；
- 贼急：伏于要害。

任意现代兵数若不能整除十，只保存三成比例，不自行规定古法未说明的取整规则。

## Partial runtime

### J4M-03 推主客相关法

`zhuke_xiangguan(...)` 已实现正文古例能够直接确定的五行相制核心：

- 客目克主目 → 客关得主人 → 客胜；
- 主目克客目 → 主人关得客 → 主胜。

正文同时说“皆用日计纳音以决之”，但本段没有展开日计纳音如何接入。当前：

- `day_nayin_element` 作为显式来源字段保留；
- 不从旧代码猜其作用；
- 不用它覆盖正文古例明确的目五行相制；
- `fully_computable=False`。

因此 J4M-03 标记为 `implemented_partial_source_specific`，不能冒充完整公式。

J4M-04 仍只有 C8-L3 的“先后/动静角色”部分实现，保持 partial。
