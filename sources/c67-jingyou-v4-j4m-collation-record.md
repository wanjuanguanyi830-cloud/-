# C67 《景祐太乙福应经》卷四与 J4M-05～11 平行文本校勘

日期：2026-10-05

## 目的

将《景祐太乙福应经》卷四对应条与《太乙金镜式经》四库本卷四 J4M 规则逐条对读。

原则：

- 《金镜》J4M canonical 不因《福应经》文字更完整而被覆盖；
- 同义平行文本可用于解释《金镜》省略句；
- 实质不同的数表、宫组、胜负断语必须作为 source variant；
- OCR/电子转录可疑字继续等待扫描图像确认。

## J4M-05 推出师法

《福应经》“释出师略地第四十八”明确作：

“行师必出其门，略地并用其二。”

并进一步写：

- 算十二、二十二、三十二；
- 门具将发；
- “出其门者，开、休、生三吉之门也”。

这为《金镜》“行师必出奇门，略地并用其二／二奇门”提供清晰平行读法。

结论：

- 出其门 = 开休生三吉门；
- 用其二 = 本条列出的 12/22/32 算条件；
- 两层继续独立；
- 《统宗》对“用其二=算得二之数”的后续解释只作第二重参校，不引入其兵额、大威离宫等扩展。

## J4M-06 推陈兵向背

《福应经》“释陈兵向背第四十九”列：

- 1 -> 西北
- 2 -> 正南
- 3 -> 东北
- 4 -> 正东
- 6 -> 正西
- 7 -> 西南
- 8 -> 正北
- 9 -> 东南

即包含 3/7/8，不列 5。

《金镜》则列 1/2/4/5/6/9，并且每项还有战利方向、背地、阵形、旗色。

故两者虽同名，结构不同。禁止：

- 用《福应经》3/7/8补《金镜》；
- 因《福应经》无5而删《金镜》5；
- 把《金镜》的阵旗细节回写《福应经》。

## J4M-07 推制阵随地法

《福应经》“释置阵随地第五十”与《金镜》共同确认：

- 水曲
- 火锐
- 木直
- 金方
- 土圆
- 主客置阵后以五行相制取胜负

这进一步支持 C66 补入的主客阵形五行相克层。

但电子转录存在两处值得后续看扫描的异读：

- 《金镜》“地洿邪” vs 《福应经》“地形跨斜”
- 《金镜》“地高而平” vs 《福应经》“地形高而不平”

后者语义明显冲突，现只登记为 transcription variant，未据 OCR 改任何 runtime。

## J4M-08 推随地制变

《福应经》“释随地形制变第五十一”在关键文字上明显更接近《汉书·爰盎晁错传》：

- 步兵地：车骑二不当一
- 萑苇竹萧：矛类兵器，长戟二不当一
- 另列曲道相伏、险阻相薄之剑楯地，弓弩三不当一
- 不习服：百不当十
- 将不省兵：五不当一

《金镜》四库本则保留 C64 已记录的一组不同数字和兵器名。

结论：

- 《福应经》+《汉书》构成强平行见证；
- 但 J4M-08 仍以《金镜》实际文字为其 source-specific canonical；
- 不做“按多数本修正文”的静默校改。

## J4M-09 太乙在天外地内

《福应经》明确：

- 地内助主 = 1/8/3/4
- 天外助客 = 9/2/7/6

与《统宗》一致，而《金镜》四库本正文只列 8/3/4 为地内。

这证明 1 宫差异至少已见于另一古代太乙文本，不只是后世《统宗》扩展。

J4M-09 仍保持：

- 《金镜》canonical = 8/3/4
- 《福应经》variant = 1/8/3/4
- 《统宗》variant = 1/8/3/4

不以两本多数结果覆盖《金镜》本身。

## J4M-10 推奇伏法

《金镜》电子转录：

“古者伏兵必败大煞之地，望敌鼓噪而发。”

《福应经》：

“古云：奇兵必从大杀之地，其地居高，去敌三五里，则鼓噪而发伏也。天目所临之下，即大杀也。”

存在实质异文：

- 伏兵 / 奇兵
- 必败 / 必从
- 《福应经》另有“居高、去敌三五里”

因此：

- 不把《金镜》“败”单字做成动作或胜负公式；
- 两本共同明确的“天目所临之下=大煞/大杀位置”继续使用；
- 《福应经》“居高、去敌三五里”只保存在 variant，不并入 J4M-10 canonical；
- 等待扫描页确认《金镜》“败”字是否抄/转有误。

## J4M-11 风云飞鸟

《福应经》“释太乙风云飞鸟置战第五十三”与《金镜》有多个实质差异：

1. 《福应经》明确区分：
   - 迫击客大将宫 -> 客败
   - 迫击主将宫 -> 主败

   《金镜》只写“迫击大将宫者主败”。

2. 《福应经》写：
   - 从主人刑上来 -> 主人败
   - 从客刑上来 -> 客败

   《金镜》电子转录写“从主人形上来客败”，胜负方向不同。

3. 《福应经》把主客目击对方“大将宫”写得更具体。

4. 《福应经》“翼主人阵前/翼客阵前”与《金镜》“扶主人阵/扶客阵”近义，但仍保留各本措辞。

5. 《福应经》把噪阵写成“众鸟翼噪，并风云冲阵而来，凶”，说明噪声不是脱离风云冲阵的独立胜负句；当前 J4M-11 对单独噪阵不补胜负仍是保守正确做法。

因此 J4M-11 暂不混合两本：

- runtime 继续服从《金镜》四库本转录；
- 《福应经》作为独立 source variant；
- “主人形/主人刑”与对应胜负优先进入扫描核字队列。
