# 《太乙统宗宝鉴》卷五“三门具不具”来源记录

## 永久规则标识

- `TZ5-THREE-DOORS`
- source profile: `tongzong_volume5_three_doors`

## 来源范围

《太乙统宗宝鉴》卷五“明三门具不具之术”。

本 profile 与四库《太乙金镜式经》卷四 `J4M-01` 分开保存，不以《统宗》补文静默改写《金镜》canonical。

## 明确规则

卷五明确说明：

1. 太乙、天目在开、生二门下，为两门不具；
2. 临休门，为三门不具；
3. 太乙、天目不在开、休、生三门之下，为门具。

第三条是《金镜》卷四现存文字没有展开的正面条件，因此只在 `TZ5` profile 中执行。

## 保守边界

以下组合本段没有明确展开，runtime 不自行补全：

- 太乙、天目同落开门；
- 太乙、天目同落生门；
- 一者临开或生，另一者在开休生之外；
- 缺太乙或天目所临门。

这些情况返回 `not_defined_by_source_passage` 或 `not_computable`，不以集合补集法强行判“门具”。

## 与五将、出师链的关系

本规则只生成 `three_doors_ready`。

- 三门不具：不可出兵；
- 五将不发：不可临战；
- 二者必须分栏；
- J4M-05 / 统宗出师规则可消费该布尔事实，但不得反写本规则。

项目另以 `CORE-WUJIANG-READY` 处理“杜塞取五将不发”的跨层口径；该整合条件不是本条原文内容。
