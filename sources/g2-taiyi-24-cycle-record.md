# G2 太乙24算行宫来源记录

## 永久规则标识

- `J1-TAIYI-24`
- runtime: `kintaiyi.taiyi_position`

## 《太乙金镜式经》卷一

“推日计太乙所在”等条明确：

1. 以太乙小周法二十四去之；
2. 余以三约之为宫数；
3. 命起一宫；
4. 顺行八宫；
5. 不游中五。

冬夏二至后的时计条又明确：

- 阳遁：一宫起，顺八宫；
- 阴遁：九宫起，逆八宫；
- 三时/三算一移；
- 不游中五。

## 《太乙统宗宝鉴》卷一

同样写：

- 入局积数；
- 太乙小周；
- 行宫率三；
- 阳一宫顺八宫；
- 阴九宫逆八宫；
- 不入中五。

部分电子OCR把“小周法二十四”识成“二百四十”。该读法不能成立，因为：

`3算/宫 × 8宫 = 24算/周`

且《金镜》明确作24。

所以canonical固定：

`SMALL_CYCLE = 24`

## 阳遁宫序

`1 -> 2 -> 3 -> 4 -> 6 -> 7 -> 8 -> 9`

每宫三算。

## 阴遁宫序

`9 -> 8 -> 7 -> 6 -> 4 -> 3 -> 2 -> 1`

每宫三算。

## 余数规则

`remainder = n % 24 or 24`

整除24属于第24算，即该周最后一宫的第三算，不回到第0位。

## 72局回归

对 `g6_72ju_paths.json`：

- 阳72：72/72；
- 阴72：72/72；
- 总计144/144太乙宫一致。

24局小周在72局中恰重复三次。

## 与旧代码

旧 `ty()` 通过构造每宫重复三次的72项映射实现同一结果。

canonical 不再构造72项表，而直接运行24算行宫公式。
