# 太乙规则的版本与来源边界

本页登记 canonical、source_variant、derived 与 pending。古籍异文只保留在来源层；不得让单一转录或 OCR 结果覆盖互校后的 canonical。规则实现只读取 canonical profile，除非调用方显式选择 source profile。

## 坐标系

- **九宫**：1乾、2离、3艮、4震、5中、6兑、7坤、8坎、9巽。代表十六辰位置分别为乾、午、艮、卯、无、酉、坤、子、巽。
- **十六辰/十六神**：子、丑、艮、寅、卯、辰、巽、巳、午、未、坤、申、酉、戌、乾、亥。大神由吕申本位沿此环固定前进四位。
- **十二支**：只用于岁支与三基等有明文支序的算法。
- **四太乙十二宫**：九宫后另有绛宫(巳)、明堂(申)、玉堂(寅)；宫号10至12原样保留。
- **五福五域**：乾戌乾亥、艮丑艮寅、巽辰巽巳、坤未坤申、中子午卯酉。

比较关系须明确使用 same_nine_palace、same_sixteen_sector、same_four_taiyi_palace 或 same_wufu_domain。不得以数字相同推定跨坐标系同宫。

## Derived

- 大神十二长生由火长生寅及顺行推导；古籍明见冠带、临官、帝旺、墓。四维艮巽坤乾的 stage 为 null。
- D8-01 的缺项由结构成分计算，经典 tags 是另一组显式集合。
- 五福/大游/小游的周期位置按各自循环公式推导，必须把原始 accumulated year 和 profile 一并保存。
- 四太乙六组同宫矩阵只记录是否同处四太乙十二宫。组合断语若无来源证据，状态为 pending。
