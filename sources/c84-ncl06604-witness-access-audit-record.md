`bibliographic_and_whole_scan_identity_verified_not_page_collated`

## 历史来源状态勘误

用户已确认：NCL-06604《太乙金镜式经》明钞本在此前整理术语库阶段**已经提供并做过扫描/初步处理**。

因此 C84 的性质不是“首次发现或首次取得该明钞本”，而是：

**在旧术语主库尚未完整迁入当前 GitHub 仓库的情况下，重新恢复并显式登记 NCL-06604 的当前可验证证据链。**

需要区分三件事：

1. 历史上该扫描本已经提供、扫描和用于术语整理；
2. 旧本地 terminology.json / 旧页级整理没有完整迁入当前仓库；
3. C84/C86 是在当前仓库中重新建立可追溯的书目、页码、异文与规则关联，不代表此前从未处理。

因此此前文中“当时只能确认书目与整卷扫描身份”的表述，仅指 **C84 当前恢复通道能直接复现出的证据状态**，不否认更早术语库阶段已经做过扫描整理。
