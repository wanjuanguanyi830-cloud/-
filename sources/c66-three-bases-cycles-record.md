# C66 君基 / 臣基 / 民基三基位置周期

日期：2026-10-05

## 1. 范围

C66 实现三基位置：

- 君基；
- 臣基；
- 民基。

唯一 runtime：

`src/kintaiyi/three_bases_cycles.py`

rule ids：

- `C66-JUNJI`
- `C66-CHENJI`
- `C66-MINJI`

同宫所主另层，不由 C66 自动推断。

## 2. 卷次见证边界

《太乙统宗宝鉴》在线见证在卷六 / 卷七编次存在差异。

C66 固定：

- `witness_volumes=[6,7]`
- 视为编次异文；
- 不复制两套算法。

三条公式本身在直接见证中稳定。

## 3. 共同邦盈差

三基均见：

`邦盈差二百五十`

所以先：

`adjusted_count = accumulated_count + 250`

再按各自周法求位。

这不是现代偏移，也不是从三基比例推出来的公共常量；是直接条文共同条件。

## 4. 君基

直接公式：

- 大周 3600；
- 小周 360；
- 行邦率 30；
- 午邦起；
- 顺行十二辰。

因此每 30 年迁一邦。

参校算例：

- 小周余 200；
- 从午起每邦30年；
- 180年走完六邦；
- 第200算落子邦第20年。

C66 用该算例锁定“余数→邦数→入邦年”的 1-based 边界。

## 5. 臣基

直接公式：

- 大周 360；
- 小周 36；
- 行邦率 3；
- 午邦起；
- 顺行十二辰。

正文另明确：

`三年迁一邦`

后期算例又见：

- 小周余2；
- 午邦第2年。

因此“臣基三年”不是由君基30年机械除十所得。

## 6. 民基

直接公式：

- 大周 360；
- 小周 12；
- 每邦1年；
- 来源转录常写“戍邦”起；
- 顺行十二辰。

由于这里明确是十二地支位置，C66 canonical 正规化为：

`戌`

但原见证字形“戍邦”保留在 source witness，不静默删除。

正文另解释：

- 君基30年一邦；
- 臣基3年一邦；
- 民基1年一易。

## 7. 周期边界

余0不解释为第0年。

固定：

- 大周余0 → 大周末项；
- 小周余0 → 小周末项；
- `state_number=12`；
- `year_in_state=years_per_state`。

下一算重新回起邦。

## 8. 同宫边界

卷六/七正文另有：

- 臣基与五福；
- 臣基与民基；
- 民基与五福；
- 三基与天乙/地乙/直符/四神/大小游等。

C66 不自动比较其他 runtime 的位置。

固定：

- `same_palace_omens_applied=False`
- `auto_same_palace_inference=False`

后续若迁同宫断语，必须做显式关系层。
