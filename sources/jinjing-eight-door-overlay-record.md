# 《太乙金镜式经》八门空间叠加来源记录

## 永久规则标识

- `J1-EIGHT-DOOR-OVERLAY`
- `J1-EIGHT-DOOR-DUTY-OVERLAY`
- `J1-YEAR-FOUR-EIGHT-DOOR-OVERLAYS`
- runtime: `kintaiyi.jinjing_eight_door_overlay`

## 卷二固定八方

《金镜》卷二“推八门所主法”给出固定次序：

`开乾 -> 休坎 -> 生艮 -> 伤震 -> 杜巽 -> 景离 -> 死坤 -> 惊兑`

项目九宫数对应：

`1乾 -> 8坎 -> 3艮 -> 4震 -> 9巽 -> 2离 -> 7坤 -> 6兑`

这定义了八门围绕外八宫顺布的空间环。

## 卷一李淳风岁计古法：四套开门盘

“推八门占岁计法”明确：

1. 开门加太乙 -> 太乙之八门；
2. 开门加主大将 -> 主大将之八门；
3. 开门加客大将 -> 客大将之八门；
4. 开门加定计大将 -> 定计大将八门。

因此实现 `jinjing_year_open_door_contexts()`，四套门盘分别以各自锚点生成，禁止压成一张共同门盘。

若主/客/定计大将因杜塞而“不出中宫”，上游应传 `None`，本层返回不可计算，不把中五伪装成外八宫。

## 直事门是另一层

卷一“推八门用法”在时计明确说“常以直门加太乙及主客大将”；卷二/《统宗》还用直事门审分野灾祥。

因此 generic `duty_door_overlay()` 只表示：

> 已知某直事门，把该门加在指定锚点宫。

它与固定“开门加锚点”并存，但不能静默替换。

## J4M-01 三门具不具

《金镜》卷四本条明确：

- 太乙、天目分临开/生二门 -> 两门不具；
- 临休门 -> 三门不具；
- 240/30求直使，并给州郡门吉凶。

本条没有明写“把直使门加太乙宫”作为三门空间步骤。

因此项目的位置辅助采用同书卷一古法“开门加太乙”求太乙/天目所临门；240/30直使只作为同条独立吉凶事实保存。

## 《统宗》卷二参校

《太乙统宗宝鉴》卷二进一步明确三张门具盘：

- 开门加太乙宫，视天目 -> 太乙之门具；
- 开门加主大将宫，视太乙、文昌 -> 主之门具；
- 开门加客大将宫，视太乙、始击 -> 客之门具。

并另说“所求直事门加定计目所在之宫”，用于四计动静吉凶。

这部分已独立实现为 `tongzong_volume2_eight_door_readiness`；不得误归卷五，也不得把定计规则与《金镜》“开门加定计大将”静默合并。
