# 《太乙金镜式经》八门空间叠加来源记录

## 永久规则标识

- `J1-EIGHT-DOOR-OVERLAY`
- runtime: `kintaiyi.jinjing_eight_door_overlay`

## 来源

### 卷二：固定八方

“推八门所主法”给出：

- 开门直乾；
- 休门直坎；
- 生门直艮；
- 伤门直震；
- 杜门直巽；
- 景门直离；
- 死门直坤；
- 惊门直兑。

按项目太乙九宫数即：

`1乾 -> 8坎 -> 3艮 -> 4震 -> 9巽 -> 2离 -> 7坤 -> 6兑`

与门序：

`开 -> 休 -> 生 -> 伤 -> 杜 -> 景 -> 死 -> 惊`

一一对应。

### 卷一：开门加锚点

“推八门占岁计法”保存古法：

- 常以开门加太乙，即太乙之八门；
- 开门加主大将，即主大将之八门；
- 开门加客大将，即客大将之八门；
- 开门加定计大将，即定计大将八门。

因此空间叠加以“开门加锚点宫”为独立规则实现。

## 与值事门严格分层

王希明另立的岁计直使法是：

`积年 -> 720 -> 240 -> 30年一门`

它回答“哪一门值事”，不是本模块的“八门如何围绕某一锚点落宫”。

时计“常以直门加太乙及主客大将”又是第三个 profile，也不得与本模块静默合并。

## 与三门具不具

太乙八门生成后，可把天目十六宫位置有损投影到外八宫，再得到天目所临门。

例如太乙在一宫：

- 一宫开；
- 八宫休；
- 三宫生；
- 四宫伤；
- 九宫杜；
- 二宫景；
- 七宫死；
- 六宫惊。

故天目在三宫即临生门，天目在八宫即临休门。

该结果可作为 J4M-01 / TZ5 三门判断的结构化上游事实。


## 动态直使门叠加补充

需要严格区分两种空间盘：

1. 李淳风古法“开门加太乙”——固定以开门为锚点；
2. 王希明/直使法的动态盘——先由岁计或时计求当期直使门，再以该直使门加太乙。

三门具不具要允许出现“太乙、天目皆不在开休生”的门具状态，因此实际自动判定必须消费**动态直使门盘**；若永远固定开门加太乙，则太乙恒在开门下，不可能出现该正面条件。

程序因此保留：
- `open_door_overlay()`：固定开门古法；
- `duty_door_overlay()` / `door_overlay(..., anchor_door)`：动态直使盘；
- `sanmen_jubu_from_positions()`：要求显式提供当期直使门；
- `sanmen_jubu_from_period_count()`：先按J4M-01的240/30周期求直使，再叠加判门。
