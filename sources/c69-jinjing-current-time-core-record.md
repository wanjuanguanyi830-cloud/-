## 2. 完整正文结构

正文分三层：

1. “二至以后日度所在，加时位（加于时支）”；
2. 天乙朝暮治神表；
3. 天乙贵神及前五、后六诸神主事 / 吉凶。

王希明按语又说明：

- 单靠时计五将不能完全决定大小将吉凶；
- 更以日度加时；
- 因步六壬式知天乙成败；
- 主客诸将在吉神下吉，在凶神下凶；
- 再与门具 / 将发 / 门杜闭塞等组合判断。

因此 C69 只能称“核心表层”，不能冒充完整排式。
