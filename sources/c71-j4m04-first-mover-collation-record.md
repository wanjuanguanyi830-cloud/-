# C71 J4M-04「推主客」先后胜负古籍参校记录

日期：2026-10-05

## 结论

《太乙金镜式经》四库本卷四“推主客”在三门具、五将发、阴阳和的有利三项后写：

> 称兵所向必克，先胜后负。

该句本身省略“起”字，若只按孤本文字，容易被实现成不指明胜方的抽象时序。

本轮用同一太乙主客兵法段的古籍平行文本参校：

- 《武经总要》后集卷十八：明确作“先起则胜，后起则败”；
- 《太乙秘书》对应段：同样明确作“先起则胜，后起则败”；
- 《景祐太乙福应经》现存 OCR 转录亦可辨同一结构，但因转录质量较低，只作辅助见证。

因此 J4M-04 canonical 将《金镜》“先胜后负”解释为：

**先起者胜，后起者败。**

## 场景落地

《金镜》本条先定义两类场景：

- 陈兵原野：先动为客，后应为主；
- 安居之势：先动为主，后应为客。

所以仅当：

- 三门具；
- 五将发；
- 阴阳和；

三项全部满足时：

- 陈兵原野：客先起 -> 客胜，主后应 -> 主负；
- 安居之势：主先起 -> 主胜，客后应 -> 客负。

## 不自动吸收的平行文本扩展

《武经总要》等平行本在“三门不具、五将不发、阴阳不和”后还继续说：

> 先起者败，后起者胜。

但四库本《金镜》本条这里只明确：

> 不利举兵，宜固守吉。

因此本轮只利用平行文本解释《金镜》已经存在但省略字词的“先胜后负”，**不把平行本额外增加的逆胜负规则自动写回《金镜》canonical**。

如以后需要保存该扩展，应另立平行 source variant。
