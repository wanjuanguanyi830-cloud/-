## 《太乙金镜式经》卷二

“推太乙运式法”明确：

- 第六步：视天地二目所在，求主客之算；
- 正宫：按本宫数起；
- 间神：以一数起；
- 行算至太乙宫止。

原书例：

太乙在九宫，大义（亥）为目：

`大义1 + 地主8 + 和德3 + 高丛4 = 16`

到巽九宫太乙即停，原例没有再加9。

因此 canonical 解释为：

> 从目起，顺十六宫而行；只累计经过的正宫数；抵达太乙正位时终止，终点太乙宫数不加入。

间神经过位本身不反复加1；“一算”只用于目从间神起算。

## 《太乙统宗宝鉴》卷二

进一步明确：

- 文昌名地目/下目，属主人之计；
- 始击名天目/上目，属客人之计；
- 正宫从宫数起；
- 间神从一而起；
- 自左顺行，依宫数算。

所以主客共用一个G6行算核心：

- 文昌 -> 主算；
- 始击 -> 客算。

## 同宫边界

直接 prose 没有把“目已经与太乙同宫”单独展开，所以必须靠立成表回归确定边界。

### 同宫正位

目本身就是太乙宫正位：

> 直接取本宫数。

这是“目之起算”，不是从外部行至太乙后再把终点加入。

### 同宫间辰

项目已锁定硬规则：

> 目与太乙同宫，但目位于该宫间辰时，强制一算，立即停止，不绕十六宫继续累计。

runtime 标记：

`rule_branch = same_palace_interstitial_forced_one`
