# 《太乙金镜式经》格局算法来源记录

## 主规则源

- **主规则来源**：《太乙金镜式经》卷三。
- **八门值事来源**：《太乙金镜式经》卷四。
- **采用模式**：`jinjing`；基本格局、复合格局和提挟关系只按本来源运行。
- **规则版本**：`jinjing-geju-1.0.0`。
- **位置模型**：十六神按 `子、丑、艮、寅、卯、辰、巽、巳、午、未、坤、申、酉、戌、乾、亥` 环列；偶数环点为八宫正宫中心，奇数点为间神。宫空间序为 `8、3、4、9、2、7、6、1`。
- **证据状态**：用户已确认规则口径并据此编写；原典具体引文页图的最终校核仍按术语库现有来源档案跟进。本仓库不把程序测试声称为古籍影像校勘。

## 规则决定与修改理由

| 事项 | 《金镜》主判 | 修改理由／边界 |
|---|---|---|
| 掩、击、格 | 始击负责掩、击、格 | 始击与太乙同正宫为掩；前后辰／宫为击；对宫为格。 |
| 囚、迫、对 | 文昌负责囚、迫、对 | 文昌必须与太乙精确同正宫才作同宫囚；与太乙相邻一辰作辰迫；对宫为对。 |
| 上目、定目 | 不加入迫 | 《金镜》以始击为上目，并明言上目无迫；定目也不进入本规则集的迫判断。 |
| 四将规则 | 主客大小／参将参与囚、迫、关、格 | 将位同宫、邻宫及客侧对宫按八宫环分别判定。关限四将互相同宫。 |
| 提挟 | 通用夹持枚举，目标限正宫 | 主体从太乙与四将中取两点，目标从太乙、四将和正宫的文昌／始击中取一点；仅当目标在八宫环上紧邻夹持两侧时输出。间神目标不并入普通提挟。 |
| 挟闭 | 独立复合规则 | 文昌、始击均在间神，并由太乙、主将、客将共同形成对二目的十六神夹持关系。 |
| 执提、提格 | 只查值事开门或生门 | 执提为值事门与太乙同宫；提格为值事门在太乙对宫。普通盘面上其他开／生门不触发。 |
| 四郭固 | 复合格局 | 由文昌囚太乙与大小将关系，或客目临太乙位置并兼客将关系组成；不单独作为一个基本位置关系。 |
| 四郭杜 | 客参与文昌并、主大与客大并，再兼掩／迫／关／格／提挟 | 旧资料出现的“主参与客大并”不是本规则的主条件。 |

## 异文与参考实现

- 《太乙淘金歌》219 年第 36 局称“客关主目”。该句保留作历史异文对照；《金镜》主算法的“关”只按四将之间同宫计算，不因此扩展为文昌与单将同宫。
- “四郭社”作为《太乙统宗宝鉴》等本的异文词形保留；本库机器主字段一律为“四郭杜”。
- `kentang2017/kintaiyi` 固定参考快照：[`11f78555d5e77c81ac8af69d243a981c22934733`](https://github.com/kentang2017/kintaiyi/tree/11f78555d5e77c81ac8af69d243a981c22934733)。此提交相对项目原研究快照 `626d8a5` 只改 README；参考代码用于复核输入表、旧摘要和历史局例，不是算法真值，也不写回该仓库。
- 局例文字对照 [`docs/example.md`](https://github.com/kentang2017/kintaiyi/blob/11f78555d5e77c81ac8af69d243a981c22934733/docs/example.md)；测试仅保存本算法需要的位置快照，不复制参考软件模块。

## 程序接口与兼容

`rules/jinjing/geju/engine.py::analyze_geju(GejuContext)` 返回同一快照的结构化盘面与格局事件；事件包含主体、目标、精确位置、成格依据、断语和来源。`to_legacy_dict()` 生成“格局键→断语”的旧式字典形状；`TaiyiGejuMixin` 提供 `shi_geju(ji_style, taiyi_acumyear)` 与结构化详情方法，宿主以 `_jinjing_geju_context()` 适配自己的盘面字段。

`Taiyi.shi_geju()` 属于参考项目的类接口，本库不包含参考项目的 `Taiyi` 类；宿主类可混入 `TaiyiGejuMixin` 并提供盘面适配方法，以保持旧字典返回形状并增加结构化详情入口。新算法本身不依赖或导入 `kintaiyi`。

## 尚未解决的范围

历史局例来自《太乙淘金歌》等不同来源，不是《金镜》每条规则的独立原典证明。局例只核对可提取的位置关系和预期差异；来源未给出的主参将等信息不由程序伪造。144 局审计为类别级对照，不要求与旧 `skyeyes_summary` 标签机械全等。
