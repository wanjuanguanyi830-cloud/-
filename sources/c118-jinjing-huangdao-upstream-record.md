# C118 《金镜》卷一黄道日度 / 宿度 / 十二分野上游

日期：2026-10-05

## 1. 目的

C69“推太乙当时法”目前已经实现：

- 十日干朝 / 暮天乙治神；
- 魁罡禁居；
- 天乙贵神与前五 / 后六天将主事、吉凶。

建立 C118 时，C69 原文要求的前置日度尚缺：

> 算二至以后日度所在，加时位（加于时支）

卷一在“推太乙当时法”之前连续给出三张上游表：

1. 推二十四气黄道日度所在立成法；
2. 推黄道数立成；
3. 推列宿十二分野立成。

并在十二分野表后明确说明：

> 算日在何宿，计属何辰，以时加位，立贵前后，以论将之吉凶。

因此 C118 将这三层单独建立为 C69 上游，不把它们混进 C69 天将表。

### 为什么仍不填 9¾ 或 10

可用作背景校验的材料包括：

- 其余27宿合计后与传统周天365¼的闭合关系；
- 《隋书》等黄道表中的“虚十”；
- 后世宿度表的“虚九少”等。

这些表的其他宿度本身也与 C118 表存在系统性差异，因此不能从“看起来能闭合”推出《金镜》本表缺失整数。

固定禁止：

- 不用365¼减其余27宿得到唯一值后反写；
- 不用《隋书》“虚十”覆盖；
- 不用后世“九少/十少”等值覆盖；
- 不把“小字四分度之一”误解释成完整宿度。

后世/平行宿度只作为校勘背景，不能覆盖《金镜》卷一当前见证。

## 6. 日度推进 helper

新增：

`term_day_position(term, day_number)`

规则：

- day_number=1 为节气本日；
- 从节气锚点开始；
- 一日推进一度；
- 依二十八宿次序跨宿；
- 只有所经宿度可安全数字化时才继续。

### 《金镜》直接实例回归

“推太乙当时法”实例写：

> 立冬六日日在心宿

C118：

- 立冬第1日 = 房1
- 第5日 = 房5
- 第6日 = 心1

与正文实例一致。

这证明“节气锚点 + 第N日按一日一度推进”的基本解释可以用于 C69 上游。

## 7. 虚宿边界

若推进必须从虚宿继续越界：

- status = `blocked_ambiguous_mansion_span`
- 不继续猜宿度。

这意味着 C118 已建立可审计的日度上游。NCL p.21 已完成影像级核定，但核定结果本身就是“整数主体仍缺失”，因此仍不声称全年任意日均完全可算。下一步若要解锁，必须取得能够**直接给出完整虚宿宿度**的独立可靠底本/校勘证据，而不是继续从总和反推。

## 8. 与 C69 / C69B 的边界

C118 已补：

- 节气 → 黄道宿度锚点；
- 宿度表；
- 宿 → 十二分野 / 地支；
- 第N日宿度推进。

C69B 已将 C118 可算的日宿与分野支接入六壬叠盘；显式输入下可执行：

- 日宿分野支加占时时支，建立天地盘；
- 按 C69 日干与朝/暮表取天乙，确定贵人落地和顺逆；
- 顺逆布十二天将，并按实体地支或九宫 adapter 查将。

当前真实边界为：

- 公历日期到节气第几日仍由上游历法提供；
- 朝 / 暮仍需显式给定；
- 虚宿整数未定，跨越该边界的输入仍为 `not_computable`；
- 九宫到十二支是有损 adapter，严格调用可直接给实体地支。

因此 C69 的：

`complete_current_time_formula=False`

只表示完整自动单入口尚未统一，不表示日度加时或六壬安将仍待实现。
