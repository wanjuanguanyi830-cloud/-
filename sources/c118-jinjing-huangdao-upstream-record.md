# C118 《金镜》卷一黄道日度 / 宿度 / 十二分野上游

日期：2026-10-05

## 1. 目的

C69“推太乙当时法”目前已经实现：

- 十日干朝 / 暮天乙治神；
- 魁罡禁居；
- 天乙贵神与前五 / 后六天将主事、吉凶。

但 C69 原文前置条件仍缺：

> 算二至以后日度所在，加时位（加于时支）

卷一在“推太乙当时法”之前连续给出三张上游表：

1. 推二十四气黄道日度所在立成法；
2. 推黄道数立成；
3. 推列宿十二分野立成。

并在十二分野表后明确说明：

> 算日在何宿，计属何辰，以时加位，立贵前后，以论将之吉凶。

因此 C118 将这三层单独建立为 C69 上游，不把它们混进 C69 天将表。

## 4. 二十八宿黄道度数

本批将可直接辨识的整数 / 半度按 Fraction 保存。

例如：

- 女11.5
- 奎17.5
- 胃14.5
- 轸18.5
- 箕10.5

### 虚宿例外

当前四库公开转录为：

`虚〈二十五分半四分度之一〉`

这一段显然存在整数主体缺失或分数标点问题。

虽然用其他历史宿度表或总周天数可以尝试反推，但 C118 不这样做。

固定：

- `numeric_span=None`
- `status=transcription_ambiguous`

后世《隋书》黄道宿度等只可作为未来校勘材料，不能覆盖《金镜》卷一当前见证。

## 6. 日度推进 helper

新增：

`term_day_position(term, day_number)`

规则：

- day_number=1 为节气本日；
- 从节气锚点开始；
- 一日推进一度；
- 依二十八宿次序跨宿；
- 只有所经宿度可安全数字化时才继续。

### 《金镜》直接实例回归

“推太乙当时法”实例写：

> 立冬六日日在心宿

C118：

- 立冬第1日 = 房1
- 第5日 = 房5
- 第6日 = 心1

与正文实例一致。

这证明“节气锚点 + 第N日按一日一度推进”的基本解释可以用于 C69 上游。

## 7. 虚宿边界

若推进必须从虚宿继续越界：

- status = `blocked_ambiguous_mansion_span`
- 不继续猜宿度。

这意味着 C118 已建立可审计的日度上游，但在虚宿度数完成影印级核定前，不声称全年任意日均完全可算。

## 8. 与 C69 的边界

C118 已补：

- 节气 → 黄道宿度锚点；
- 宿度表；
- 宿 → 十二分野 / 地支；
- 第N日宿度推进。

C69 之后仍需：

1. “以时加位”如何将日宿所属地支加到时支；
2. 六壬式天乙贵神在十二支上的完整落位；
3. 再把主客大小将落到吉神 / 凶神下作最终判断。

因此 C69 仍保持：

`complete_current_time_formula=False`

但 pending 已从“日度完全没有上游”收缩为：

“日度上游已有 C118；时支加位和六壬式安将仍待实现”。
