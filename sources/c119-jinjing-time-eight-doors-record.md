# C119 《金镜》卷一“推八门用法”时计直门

日期：2026-10-05

## 1. 直接来源

《太乙金镜式经》卷一“推八门用法”：

阳遁四门：

- 开
- 生
- 惊
- 休

阴遁四门：

- 杜
- 死
- 伤
- 景

共同：

- 三十时一移门；
- 常以直门加太乙及主客大将随数而行；
- 太乙三时一移；
- 大将一时一移。

王希明明确说明其实际取法以冬至/夏至初临之时起门、时尽则移，
不拘张良旧说所举甲/丙/己/辛日锚点。

直接见证：

- https://zh.wikisource.org/zh-hans/太乙金鏡式經_(四庫全書本)/卷01
- https://www.shidianguji.com/book/SK1615/chapter/1l9lir739kc96

## 2. 冬至加时所直门

正文：

- 天正时实以240去之；
- 不尽再以120去之；
- 不尽以30约之为门数；
- 命起开门，以次而行。

C119：

- 0..29 → 开
- 30..59 → 生
- 60..89 → 惊
- 90..119 → 休
- 120 后循环；
- 外层仍记录 mod240。

## 3. 夏至加时所直门

正文可见：

- 夏至时实以120去之；
- 不尽以30约之为门数；
- 后文有缺。

但紧邻“推八门用法”已直接给：

- 阴遁杜、死、伤、景；
- 三十时一移门。

因此 C119 采用：

- 0..29 → 杜
- 30..59 → 死
- 60..89 → 伤
- 90..119 → 景

并标：

`cross_section_direct_sequence_with_local_lacuna`

不是把缺文伪装成完整逐字见证。

## 4. 与现有 rules/jinjing/eight_door.py 分离

当前仓库旧文件：

`rules/jinjing/eight_door.py`

实现的是：

- 240年周期；
- 30年一门。

C119 是：

- 时实；
- 30时一移门；
- 阳/阴各四门。

两者不是同一个公式。

固定：

`same_formula=False`

不得拿“30年一门”替代“30时一门”，也不得反过来。
