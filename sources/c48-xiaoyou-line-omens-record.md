# C48 小游统卦行爻所主灾祥记录

## 直接来源

《太乙统宗宝鉴》：

- 明小游统卦行爻所主灾祥术

当前识典主见证编在卷十：
https://www.shidianguji.com/book/CADAL02055529/chapter/1l5eriw9odw6f

另有目录/分页把本术接在卷九末，固定：

`volume_status="witness_volume_boundary_variant"`

## 1. 与 C47 的关系

C48 消费：

`C47-XY-HEX`

只读取：

- 内卦动爻；
- 外卦三才；
- 上下卦结构。

C48 不：

- 重算小游轨运；
- 强制命名六十四卦；
- 调用旧 `najia_for_yao`；
- 使用大游 epoch。

## 2. 爻位层

原文固定：

- 二、五：行于中道，安平；
- 初、四：算和且有应为吉；
- 初、四：不和且无应，君臣失助、世不宁；
- 三：内极，事多凶变，但较轻；
- 六：外极，事多凶变，较重。

对初/四：

- `calc_harmonious`
- `has_response`

必须显式输入。

若一真一假：

`mixed_evidence`

不强行归吉凶。

## 3. 三才层

C47 外卦三年分别：

- 理天；
- 理地；
- 理人。

C48 对应灾象：

### 理天

- 天有变异
- 日月失辉
- 五星不经其度

### 理地

- 风雨不调
- 禾谷不成

### 理人

- 人民疾疫
- 时多荒俭

## 4. 格局层

直接正文见：

- 关
- 囚
- 掩
- 迫
- 击
- 挟
- 格
- 对

另有 OCR / 排版见“格封”。

C48 保存：

- `readings=["格对","格封"]`
- 正规化结构仍按已知格、对分项。

格局只增加：

- 水旱灾伤
- 兵刃饥馑
- 疾疫流亡

固定：

`patterns_aggravate_only=True`

不得覆盖基础爻位判断。

## 5. 纳甲层

C48 不从重卦名反推纳甲。

必须由上游显式提供：

`moving_line_najia=[天干, 地支]`

缺纳甲时：

`partial`

而不是强制构造六十四卦名。
