# C42 卷九历数长短 / 安居之代历数记录

## 1. 直接来源边界

本批只处理《太乙统宗宝鉴》卷九：

- 明历数长短，以观远近之期术
- 明安居之代历数之期术

C42 不负责：

- 从积年推内外卦；
- 选择 +34 / +36610 等纪元差；
- 调用 C38 阳九百六行限轨迹；
- 自动排六爻纳甲；
- 用矛盾历史算例猜完整帝祚年数。

## 2. C41 策数回修

卷九算例直接显示：

- 乾内卦策 = 108
- 震外卦策 = 84
- 重卦总策 = 192

另有：

- 坤内卦策 = 72
- 乾外卦策 = 108
- 重卦总策 = 180

因此 C41 原表：

- 乾36
- 坤24
- 震坎艮28
- 巽离兑32

是单爻四象策数，而不是整个三爻经卦总策。

固定：

`trigram_ce = per_line_ce × 3`

## 3. 纳甲干支数

直接表：

- 甲 / 己 / 子 / 午 = 9
- 乙 / 庚 / 丑 / 未 = 8
- 丙 / 辛 / 寅 / 申 = 7
- 丁 / 壬 / 卯 / 酉 = 6
- 戊 / 癸 / 辰 / 戌 = 5
- 巳 / 亥 = 4

统宗在线 OCR 末组见“己亥四”，与前面“己=9”自相冲突；
独立见证明确为“巳亥四”。

因此：

- 保留 OCR witness
- 正规化为 巳亥
- 标记 `ocr_corrected_by_collation`

## 4. 爻位加数

固定：

### 初、四爻

只加本爻纳甲干支数。

例：

甲子 = 9 + 9 = 18。

### 二、五爻

六爻全部纳甲干支数求和后倍加。

必须取得六爻全部纳甲；少一爻则：

`not_computable`

### 三、六爻

亢极：

`不倍不加`

加数固定 0。

## 5. 策数除减中间量仍有算例冲突

当前历史算例至少出现：

### 洪武例

- 外卦相关余数 535
- 重卦总策 180
- 除减后余 175

算术一致：

`535 % 180 = 175`

### 万历己未例

见证同时出现：

- 相关余数 146
- 重卦总策 192
- 后文称余 48

该组数字不能按同一普通取余公式直接成立。

因此 C42 固定：

`status="source_example_conflict_requires_explicit_base"`

`automatic_remainder_formula=None`

运行时只有调用方显式提供：

`base_remainder_after_ce`

才继续加纳甲数得到最终历数。

绝不因洪武例成立就把 `%` 强塞给所有见证。

## 6. 安居之代基础爻位

固定：

- 初：历数长
- 二：历数长，正旺
- 三：历数短，内极，灾较轻
- 四：历数长
- 五：历数长，时已过
- 六：历数短，外极，灾较重

此外：

- 阴阳得位 → 政治安
- 阴阳失位 → 政治乱
- 阳爻有应 → 君得臣助
- 阳爻无应 → 君失臣辅
- 君臣合 → 政亨
- 君臣格 → 政乖

这些都是附加证据，不能覆盖“一二四五长、三六短”的基础分类。

掩迫囚击格挟、阳九百六首尾等也继续作为独立 corrections / evidence。
