# 五运六气、五音之数与卷九/卷十术语统一记录

## 一、五运六气与五音之数

稳定术语入口：

- terminology/wuyun-wuyin.json

### 卷三五运六气

规则：C37-V3-WYUN

职责：

- 五运；
- 文昌为主气；
- 始击为客气；
- 统行框架。

不计算：

- 岁会；
- 太乙天符。

### 卷十五运六气

规则：C37-V10-WYUN

C39负责卷十细表校勘：

- 五运配五音；
- 六气配五行；
- 太过/不及/平气纪名；
- 合会枚举见证。

当前不得强行解决：

- 天会/岁会/逆会/辐辏的见证差异；
- 缺九宫天符/三旗输入时的太乙天符公式；
- 只凭年干直接最终判太过/不及。

### 五音之数

规则：C37-V3-WYIN

来源只属统宗卷三。

共享核心：

- 1/2 宫土人君
- 3/4 徵火宗庙
- 5/6 羽水后妃
- 7/8 商金子孙
- 9/10 角木疾病

该核心复用 D8-03。

禁止：

- 接入 D8-08 数有所主；
- 因卷十“五运配五音”而把五音之数改标成卷十规则。

## 二、卷九 / 卷十剩余规则

稳定入口：

- terminology/volume9-10.json

### C41 太游内外重卦

卷九直接术文。

固定：

- 乾36、坤24、震坎艮28、巽离兑32均为单爻策数；
- 经卦策数 = 单爻策数 × 3；
- 重卦总策 = 内外经卦策数和；
- 内卦36年，6年一爻；
- 外卦动爻当前未证；
- +34 / +36610 / legacy +50 不由 C41 runtime 选择。

### C42 历数长短 / 安居

固定纳甲干支数表。

爻位：

- 初四：本爻单加；
- 二五：六爻全量后倍加；
- 三六：不加。

基础长短：

- 一二四五长；
- 三六短。

策数除减后的中间余数仍有算例冲突，因此必须显式提供 base_remainder_after_ce。

### C43 厄会行限

当前在线卷十 / 项目旧卷九。

必须：

- 完整即位年六十甲子；
- 太阳落点；
- 阴主落点；
- 大武/和德顺逆；
- 神数累计证据。

旧十六点简单步数非 canonical。

### C44 国政革易 / 法令变更

当前在线卷十 / 项目旧卷九。

统宗六神核心：

- 太簇
- 太阳
- 阴主
- 地主
- 武德
- 大义

算长且和 -> 远；
算短不和 -> 近。

具体年数只作 witness candidates：

- 远：90 / 180
- 近：统宗 9 / 28
- 近：太白兵备 9 / 18

不选 canonical 单一年数。

### C45 岁中灾发月日之期

两阶段：

1. 岁 -> 月；
2. 月 -> 日。

两阶段都必须分别看：

- 文昌；
- 天目。

四维落点无直接月份折算时保持 not_computable。

日层只保存十六点/地支候选，不伪造现代具体日期。

### C46 阴阳九厄

九段长度：

106 / 374 / 480 / 720 / 720 / 600 / 600 / 480 / 480

必须累计成4560时间轴。

灾年：

9 / 9 / 9 / 7 / 7 / 5 / 5 / 3 / 3

合计57。

五阳主旱，四阴主水。

702/720、第四段阴阳字、第九段3/5年均保留原 witness 与正规化理由。

## 三、历法边界

以上所有古法层都不得改变 production 历法：

- 太乙岁只在真实天文冬至交节瞬间切换；
- 元旦、春节、立春、春分不参与换年；
- 古籍“月/日之期”若没有现代历法换算证据，不伪造现代公历日期。
