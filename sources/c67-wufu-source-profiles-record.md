# C67 五福太乙位置来源 profile

日期：2026-10-05

## 1. 结论

五福位置存在至少两套不可静默合并的来源公式。

稳定共同核心：

- 五宫：乾、艮、巽、坤、中；
- 宫名：黄秘、黄始、黄室、黄廷、玄室；
- 每宫45年；
- 五宫共225年。

但外层周法 / 盈差不同。

因此 C67 要求调用方显式提供：

`source_profile="tongzong" | "jinjing"`

没有默认 profile。

## 2. 统宗 profile

《太乙统宗宝鉴》卷六 / 卷七见证：

- 宫盈差115；
- 大周2250；
- 小周225；
- 行宫率45；
- 乾→艮→巽→坤→中。

C67 rule：

`C67-WUFU-TONGZONG`

算法：

1. 积年 + 115；
2. 以2250取大周；
3. 再以225取小周；
4. 以45年分宫；
5. 乾、艮、巽、坤、中顺行。

卷六/卷七只作编次见证 variant，不复制公式。

## 3. 金镜 profile

《太乙金镜式经》卷五：

- 225年一周；
- 45年一宫；
- 乾→艮→巽→坤→中；
- 该段不见统宗的宫盈差115；
- 也不见统宗2250外层大周。

C67 rule：

`C67-WUFU-JINJING`

因此不得把统宗115写回金镜。

## 4. 金镜历史算例

金镜给：

- 开元十二年积13331；
- 五福在辽东；
- 入宫第11年。

计算：

- 13331 mod 225 = 56；
- 前45年为乾；
- 第46–90年为艮；
- 56为艮宫第11年。

C67 已用此例锁定金镜 1-based 边界。

## 5. 后期太白兵备异文

《太白兵备统宗宝鉴》后期算法段另见：

- 加宫盈差250；
- 同页周数字样又有225 / 250冲突。

这既不同于：

- 统宗 +115 / 2250→225；
- 金镜无盈差 / 225。

因此 C67 只登记：

`formula_variant_pending_audit`

固定：

- `implemented=False`
- `canonical_selected=None`

未完成独立见证校勘前，不实现第三 profile。

## 6. 五福吉算严格分层

《统宗》“明五福吉算所利术”虽紧邻五福位置，但属于另一规则：

- 225年一周；
- 45年一宫；
- 按吉算数值区分君主、公侯、后妃、太子、民、师帅、上中下将、士卒。

C67 不解释这些受益对象。

固定：

- `auspicious_number_layer_applied=False`
- 留给 C68。

## 7. 同宫断语严格分层

五福与君基 / 臣基 / 民基 / 四神 / 大小游等同宫断语也不进入 C67。

固定：

- `same_palace_omens_applied=False`
- `auto_same_palace_inference=False`

## 8. C15 状态

`明五福太乙所主術`

现 action：

`use_c67_wufu_tongzong_profile`

因为 C15 该字段的主来源是统宗。

`明五福吉算所主術`

仍保持：

`source_verified_split_runtime_next`

两者不得合回一个旧 flat 字段。
