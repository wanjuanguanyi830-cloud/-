## V17-05 敌兵来方将卒多寡

来源条件严格区分：

- 时计阳 → 有贼
- 时计阴 → 无贼
- 5/15/25/35 → 八门杜塞，不来
- 15以下（非杜塞） → 兵寡、无将
- 16以上且阴阳和 → 兵众、有将有卒
- 16以上但不和/未知 → 不满足来源大兵充分条件

因此禁止旧式：

`away_cal >= 16 => 必然兵众`

来方不再由宫位粗映射推断，而要求上游提供客目：

- 左 → 东
- 右 → 西
- 前 → 南
- 后 → 北
- 四维 → 四维
