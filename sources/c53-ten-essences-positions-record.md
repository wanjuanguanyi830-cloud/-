日期：2026-10-05

## 范围

C53 只实现已经完成来源校勘的十精位置推步：

- 飞鸟
- 五风
- 太尊
- 八风
- 三风
- 五行

十精云气断事继续独立，不在 C53 自动输出。

C53 本模块不实现的项目：

- 天皇 → C55-TIANHUANG；
- 帝符 → C55-DIFU；
- 天时 → 来源冲突 pending；
- 太乙数 → C54-TAIYI-NUMBER（数值层，不是宫位函数）。

## 1. 通用边界

所有已实现十精：

- 调用方必须显式提供阳 / 阴遁；
- C53 不从现代日期自动推阴阳遁；
- 先按各自大周、再按小周取当期；
- 余 0 视为周期末项，不生成第 0 项；
- 不采用正文明确否定的宫盈差；
- 不附带十精云气所主断语。

## 2. 飞鸟

直接主见证：

- 大周 90；
- 小周 9；
- 阳局起一宫，顺行九宫；
- 阴局按阳局对冲。

《太白兵备统宗宝鉴》参校：

- 阳起乾；
- 阴起巽；
- 阳顺阴逆；
- 游行九宫。

因此：

- 阳：1→2→3→4→5→6→7→8→9；
- 阴：9→8→7→6→5→4→3→2→1。

旧 config.flybird 的 %8 不等价。

十精“飞鸟”是推步神位，不得替代 J4M-11 外部飞鸟观测。

## 3. 五风

- 大周 90；
- 小周 9；
- 一三五七九、二四六八；

固定：

- 武经 9/7 互换读法作为 source variant 保留；
- 不宣称跨传本唯一。

旧 config.fivewind 的 %29 不等价。

## 5. 八风

## 6. 三风

统宗主见证：

3→7→2→6→1→5→9→4→8

《太白兵备》阳序与统宗一致，并给阴序：

7→3→8→4→9→5→1→6→2

《武经总要》一见证作“起五宫，次七二六一五九四八”，与统宗/太白起点冲突。

固定：

- canonical profile 采用统宗主见证；
- 太白作为一致参校；
- 武经起五宫保留为 source variant；
- 不静默覆盖。

旧 config.threewind 的八项序列漏了“9”，不等价。

## 11. C53 / C55 去重

并行过程中 C53 曾短暂加入 `C53-DIFU`。

该实现没有复用已校十六神顺序，阴主戌之后误接了阳德；C55 统一复用 `taiyi_rules.GOD_POSITION` 后确认应为：

`阴主戌 → 阴德乾 → 大义亥 → 地主子`

因此：

- 删除 C53-DIFU；
- 帝符唯一 canonical 固定为 C55-DIFU；
- 天皇 / 帝符统一由 C55 十六神重留模型承担；
- C53 保持六项九宫/四正型 runtime。
