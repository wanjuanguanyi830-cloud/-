# 现代 production 月计太阳月界

## 永久规则标识

- `MODERN-TAIYI-SOLAR-MONTH`
- runtime: `kintaiyi.taiyi_modern_solar_month`

## 原典边界

《太乙金镜式经》卷一“推六纪月建法”明确：

> 若有闰月，只以逐月节气时刻为正也。

因此现代production采用：

> **真实天文“节”交节瞬间作为月界。**

不是：

- 公历每月1日；
- 农历朔日；
- 春节；
- 闰月开始日。

闰月不会给太乙月计额外插入一个第13月界。

## 十二节与月建

- 大雪 -> 子月
- 小寒 -> 丑月
- 立春 -> 寅月
- 惊蛰 -> 卯月
- 清明 -> 辰月
- 立夏 -> 巳月
- 芒种 -> 午月
- 小暑 -> 未月
- 立秋 -> 申月
- 白露 -> 酉月
- 寒露 -> 戌月
- 立冬 -> 亥月

交节瞬间本身进入新月。

## 现代天文计算

使用 `astronomy-engine.SearchSunLongitude()`：

- 小寒 285°
- 立春 315°
- 惊蛰 345°
- 清明 15°
- 立夏 45°
- 芒种 75°
- 小暑 105°
- 立秋 135°
- 白露 165°
- 寒露 195°
- 立冬 225°
- 大雪 255°

所有比较均用UTC绝对瞬间。

## 与现代农历事实层

例如2025-07-25是现代农历闰六月初一。

但它处在：

`小暑 -> 立秋`

之间，所以太乙production太阳月仍是：

`未月`

不会因“闰六月”多推进一次月计。

这正是“现代农历事实”和“太乙月界事实”分层的目的。
