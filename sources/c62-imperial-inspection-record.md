# C62 《太乙统宗宝鉴》卷五“明天子巡狩之期术”

日期：2026-10-05

## 1. 范围

C62 只实现三个来源明确的结构：

1. 巡狩年是否成立；
2. 巡狩出方；
3. “囚 / 挟 / 格 / 对”为行期之月的显式条件检查。

唯一 runtime：

`src/kintaiyi/imperial_inspection.py`

rule id：

`C62-IMPERIAL-INSPECTION`

不在 C62：

- 不从日期或积年自动推太乙；
- 不自动推天目 / 文昌；
- 不从其他格局模块自动制造囚、挟、格、对；
- 不自行输出具体月份。

## 2. 《太乙统宗宝鉴》卷五主见证

题：

`明天子巡狩之期术`

稳定规则：

- 欲知巡狩之年，视太乙与天目在四维之岁；
- 太乙、天目都在四维，才是巡狩之期；
- 若不巡狩，则见临轩 / 遣使按行风俗等替代行为；
- 出何方，以天目 / 文昌所临而决；
- 另见“太乙囚挟格对之下，是谓行期之月”。

C62 把“巡狩年”“出方”“行月条件”拆成三个字段，不再保存成一条旧中文 flat 断语。

## 3. 《太乙金镜式经》卷十独立参校

〈推天子巡狩〉同样明确：

- 太乙与天目在四维之岁为巡狩；
- 若不出则遣使者按行风俗；
- 出方以主目所临起处决。

其四维出方与统宗稳定一致：

- 阴德 / 乾 → 东方；
- 和德 / 艮 → 南方；
- 大炅 / 巽 → 西方；
- 大武 / 坤 → 北方。

因此 C62 以“天目四维位置”作为方向规则事实。

## 4. 西方神名见证异读

统宗在线不同 OCR / 转写在巽位神名处见：

- 太昊；
- 太靈；

《太乙金镜式经》见：

- 大炅。

本库十六神 canonical 亦为：

`大炅 = 巽`

但 C62 不把 OCR 神名异读强行宣布为同一原字。

固定：

- 稳定位置：巽；
- 稳定方向：西方；
- canonical 方向规则按位置；
- “太昊 / 太靈 / 大炅”留在 witness 层。

## 5. 四维判定

四维固定：

`乾 / 艮 / 巽 / 坤`

C62 要求：

`taiyi_position in 四维 AND tianmu_position in 四维`

才：

`inspection_year=True`

只一方在四维，不成立。

天目出方只在巡狩年成立时输出。

## 6. 行期之月边界

统宗卷五只在本条写出：

`太乙囚挟格对之下，是谓行期之月`

当前直接段落没有给：

- 囚对应某月；
- 挟对应某月；
- 格对应某月；
- 对对应某月；
- 或任何数值月份换算表。

所以 C62 固定：

- `month_patterns` 必须显式输入；
- 允许囚 / 挟 / 格 / 对；
- `month_condition_met` 只表示来源条件被显式命中；
- `month_number=None`；
- `month_number_computation_supported=False`。

不得把“条件成立”误写成“已经算出几月”。

## 7. 旧 flat 边界

旧字段：

`明天子巡狩之期術`

仍：

`migrate_whole=False`

因为旧 flat 可能揉在一起保存：

- 年期；
- 出方；
- 行月；
- 说明文字。

C62 必须从显式太乙位、天目位和月格局证据重新计算。

## 8. 来源分层结论

C62 的 canonical 选择不是把统宗与金镜混成新公式，而是：

- 统宗卷五为主 source profile；
- 金镜卷十用于独立参校稳定核心；
- 神名 OCR 差异只留 witness；
- 金镜未见的统宗“行月条件”不反推入金镜来源；
- 无直接月份换算则明确不计算。
