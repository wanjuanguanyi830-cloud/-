## 2. 《太乙统宗宝鉴》主公式

卷十八直接见证：

- 大周 120；
- 小周 12；
- 余命起吕申；
- 顺行十二辰；
- 阴局取阳局对冲。

十六神基准中吕申在寅，因此阳局路径：

`寅 → 卯 → 辰 → 巳 → 午 → 未 → 申 → 酉 → 戌 → 亥 → 子 → 丑`

阴局逐步取对冲后：

`申 → 酉 → 戌 → 亥 → 子 → 丑 → 寅 → 卯 → 辰 → 巳 → 午 → 未`

两遁都按十二地支顺行。

## 3. 《太白兵备统宗宝鉴》内部异文

同一页面存在两层文字：

### 前置总括句

见：

`天时阳起于申，阴起于寅，顺行地支一十二宫`

### 后续完整推步正文

却明确写：

- 阳遁起寅；
- 阴遁起申；
- 两者均顺行十二宫；
- 后文再次总结“阳寅阴申起”。

完整推步正文与《统宗》一致。

因此 C56 不把二者混成折衷公式，而是：

- 采用《统宗》主公式；
- 以太白“完整推步正文”作一致参校；
- 将太白“前置总括句阳申阴寅”保存为 `intro_summary_variant`；
- 不删除该异文，也不让它覆盖详细算法段。
