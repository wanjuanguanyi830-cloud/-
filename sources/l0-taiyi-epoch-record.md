# L0 历元：卷一长积年、六纪三元、卷三五子元短积年

## 永久规则标识

- `J1-ACC-01`：卷一长积年；
- `J1-SIX-JI-THREE-YUAN`：六纪三元；
- `J3-ACC-01`：卷三五子元短积年；
- `J3-FIVE-ZI-360`：五子元360周；
- runtime: `kintaiyi.taiyi_epoch`

## 一、卷一长积年

《太乙金镜式经》卷一“推上元积年”：

- 开元十二年甲子积：`1,937,281`；
- 上考往古，每年减一；
- 下检将来，每年加一。

因此以724 CE为锚：

`long_count = 1,937,281 + 年差`

项目历史年份接口：

- CE为正；
- BCE为负；
- 不设0年；
- 1 BCE=-1，1 CE=1。

这里的“年”只表示岁计已经解析好的历史年号，不负责公历日期与传统岁界转换。

## 二、六纪三元

《金镜》卷一：

> 360去之，再以纪法60去之，所得为纪数，不尽为入纪年数。

《太乙统宗宝鉴》卷二“明太乙入统年之法”把三元标签直接列清：

1. 第一纪：上元；
2. 第二纪：中元；
3. 第三纪：下元；
4. 第四纪：上元；
5. 第五纪：中元；
6. 第六纪：下元。

开元十二年甲子明确列为：

> 下元甲子岁入第三纪。

而长积年：

`1,937,281 % 360 = 121`

故：

- 第三纪；
- 入纪第一年；
- 下元。

### 重要边界

这里的“三元”是**六个60年纪的元标签循环**，不是把每个60年纪再分成三个20年。

不得把后世玄空“三元九运”的20年分法回填本条。

## 三、卷三五子元短积年

《金镜》卷三“五子元积年立成法”：

> 上元甲子至开元十二年甲子，岁积三万一算。

项目按：

`30,001`

保存。

同条又规定：

- 先以360去之；
- 再以72约之；
- 不尽为入元局数。

因此五子元：

1. 甲子：1..72；
2. 丙子：73..144；
3. 戊子：145..216；
4. 庚子：217..288；
5. 壬子：289..360。

开元十二年：

`30,001 % 360 = 121`

所以为：

- 丙子元；
- 第49局。

## 四、两历元关系

同一724 CE：

- 卷一：1,937,281；
- 卷三：30,001。

差：

`1,937,281 - 30,001 = 1,907,280 = 360 × 5,298`

因此二者：

- 数值不同；
- 历元来源不同；
- 在360/72/24/18/60等当前岁计周期上同余。

项目政策：

> 保留两个真实source profile；只声明“mod360等价”，绝不把30,001改写成1,937,281的别名。

## 五、与G1～G7

正式现代入口：

`历史年份 -> J1-ACC-01长积年 -> G1～G7`

卷三短积年主要用于：

- 五子元立成校验；
- 历元缩短算法；
- 与长积年做360同余交叉验证。
