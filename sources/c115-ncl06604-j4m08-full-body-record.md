## 一、开头“三急”

明钞本：

**晁错曰：用兵临战合用之急者有三：一曰士卒服习，二曰随其地形，三曰善用兵器。**

三急：
1. 士卒服习
2. 随其地形
3. 善用兵器

## 二、五类地形—兵种/兵器—比例

### 1. 步兵地

**五丈之沟居堑之水山林积石川泽丘阜草木所临，此步兵之地也，车骑三不当一。**

- favored = 步兵
- ratio = 车骑三不当一

### 2. 车骑地

**土山平陵曼行相属平原旷野，此车骑之地也，步卒十不当一。**

- favored = 车骑
- ratio = 步卒十不当一

保留明钞本实际词形“土山”“曼行”“平原旷野”“步卒十不当一”，不以其他见证静默替换。

### 3. 长戟地

**两阵相近平地浅草，可前可后，此长戟之地，剑楯三不当一。**

- favored = 长戟
- ratio = 剑楯三不当一

### 4. 矛鋋地

**萑苇竹萧草木蒙笼枝叶接茂，此矛鋋之地也，弓弩三不当一。**

- favored = 矛鋋
- ratio = 弓弩三不当一

这再次支持 C79 的“矛鋋”，而不是旧电子转录“矛锤”。

### 5. 弓弩地

**平阳相远山谷幽涧仰高临下，此弓弩之地也，短兵百不当一。**

- favored = 弓弩
- ratio = 短兵百不当一

## 三、训练段

明钞本直接可读：

**士不选练，卒不服习，起居不精，动静不禁，避难不反，前击后解，与金鼓之指相失，此士不习勤卒之过也，百不当一。**

特别保留：
- 动静不禁
- 避难不反
- 此士不习勤卒之过也
- 百不当一

## 四、器械 / 将帅段

明钞本：

**兵不完利，与空手同；中不能入，与无镞同；此将不习兵之过也，五不当一。**

这是本轮最重要的新实质异文之一。

NCL 明钞本：
- 将不习兵 -> 五不当一

四库 J4M-08 当前 profile：
- 将不习兵 -> 十不当一

《汉书》《景祐太乙福应经》对应体系：
- 将不省兵 / 将不习兵相关层 -> 五不当一

因此 NCL 在这一项的数值接近《汉书》/《福应经》，但其余多项比例又与四库一致，不能把 NCL 简单归入任何一系。

## 五、指挥链

明钞本：

**兵法曰：器械不利，以其卒与敌也；卒不可用，以其将与敌也；将不知兵，以其主与敌也；君不择将，以其国与敌也。此四者用兵之至要也。**

四层分别是：
1. 器械不利 -> 卒与敌
2. 卒不可用 -> 将与敌
3. 将不知兵 -> 主与敌
4. 君不择将 -> 国与敌

继续只作 doctrine / warning 层，不转换成现代战力分数。

## 六、收尾

明钞本：

**是以太乙用兵之道，克敌于未来，制胜于未兆，临敌观变在于将也。故曰出兵当从奇门，临敌随形制变，此之要也。**

紧接下一标题：

**推太乙在天外地内法**

因此 J4M-08 / J4M-09 页内边界也直接确认。
