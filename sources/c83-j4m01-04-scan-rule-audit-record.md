# C83 《太乙金镜式经》卷四 J4M-01～04 影印边界与“太蔟/太簇”术语归一

## 目标

继 C79/C80 后，继续复扫 J4M-01～J4M-04：

- 三门具不具；
- 五将发不发；
- 主客相关法；
- 推主客。

本轮重点不是扩公式，而是锁定原文明确范围、古籍参校边界，并解决四库原文字形“太蔟”与项目规范词形“太簇”的输入兼容。

## J4M-01 推三门具不具

四库本明确：

- 三门 = 开、休、生；
- 太乙、天目在开/生二门下 -> 两门不具；
- 在休门下 -> 三门不具；
- 直使二百四十为一周、每三十移一门；
- 州郡岁计：开休生大吉、景小吉、死惊伤杜大凶。

当前仍采取保守实现：

- 太乙、天目分临开/生二门，判两门不具；
- 临休，判三门不具；
- 同落开、同落生、只给一端等本句未展开组合不自动判“三门具”。

《统宗》有更明确的补充说明，但不静默回写《金镜》source profile。

## J4M-02 推五将发不发

正文阻断层固定为：

- 始击有无掩击；
- 文昌有无囚迫；
- 主客大小将有无相关。

并明确：

- 三门不具 -> 不可出兵；
- 五将不发 -> 不可临战。

因此 runtime 继续分栏：

- five_generals_released
- three_doors_ready
- combined_ready

不得仅因“三门具”而在五将阻断事实未知时直接宣称“五将发”。

## J4M-03 推主客相关法

canonical 继续：

- 日计主客二目所临十六神五行；
- 客目克主目 -> 客关得主人 -> 客胜；
- 主目克客目 -> 主人关得客 -> 主胜；
- 无相制 -> 《金镜》本条不强判胜负。

古籍参校：

- 《景祐太乙福应经》：“日计二目纳音”；
- 《太乙淘金歌》：“二目纳音……取五行生克为用”。

因此不得恢复旧错误模型“当天干支六十甲子纳音”。

### 太蔟 / 太簇

四库卷四首例写“太蔟为天目金神”。

项目规范词形此前使用“太簇”。C83 将其登记为同一神名的来源字形 alias：

- source_form = 太蔟
- canonical_form = 太簇
- element = 金

runtime 行为：

- 接受“太蔟”输入；
- 保留原始输入；
- 另输出 canonical “太簇”；
- 五行关系不变。

登记位置：

- terminology/jinjing-v4-aliases.json
- rules/jinjing_v4_military.json
- src/kintaiyi/jinjing_v4_military.py

这只是词形归一，不是创建 source variant。

## J4M-04 推主客

固定层：

- 陈兵原野：先动为客，后应为主；
- 安居之势：先动为主，后应为客；
- 三门具 + 五将发 + 阴阳和：称兵所向必克；
- 《金镜》“先胜后负”只以《武经总要》《太乙秘书》同段“先起则胜、后起则败”解释；
- 三项皆不利：《金镜》只明不利举兵、宜固守吉。

不补：

- 不把其他传本“三项皆恶先起败后起胜”等扩展回写 canonical；
- 混合条件不扩写；
- 不把 J4M-03 五行相关胜负或 D8-06 多少胜负并入本条。
