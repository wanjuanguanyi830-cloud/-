# 《景祐太乙福应经》卷四 JF4M-01..11 独立 runtime 记录

## 目标

将此前仅有 source-record 的 JF4M-01..11 全部拆成《福应经》自身 source-specific runtime。

新增：

- src/kintaiyi/jingyou_fuying_v4_military.py

固定：

- source_profile = jingyou_fuying_volume4
- ruleset = jingyou-fuying-v4-military-11
- cross_source_merge = false
- 禁止调用 J4M 平行函数作为算法替代

## JF4M-01 三门

实现：

- 开、休、生为三门；
- 太乙/天目临休 -> 三门不具；
- 太乙、天目分临开/生 -> 二门不具；
- 240一周、30一易直使，开起次休顺八门。

年月日时如何换成累计数仍由上游负责。

## JF4M-02 五将

明确条件：

- 始击无掩击；
- 文昌无囚迫；
- 第三条件满足。

第三条件电子转录作“大小将不相开”，目前待扫描核字。

runtime 使用 third_condition_clear：

- True = 调用方已确认本来源第三条件满足；
- False = 已确认不满足；
- None = 不可判。

不得把该字段自动解释成 J4M-02 的“主客大小将无相关”。

## JF4M-03 主客相关

只按日计二目所临神五行相制：

- 客目克主目 -> 客胜；
- 主目克客目 -> 主胜；
- 无相制 -> 本条不宣胜负。

十六神五行只复用公共 common-core，不调用 J4M-03 runtime。

## JF4M-04 主客

- 陈兵原野：先起为客、后动为主；
- 安居之势：先举为主、后应为客；
- 三门具、五将发、阴阳和：先起者胜；
- 三项皆不利：宜固守；
- 混合组合未明时不扩写。

## JF4M-05 出师略地

四条件分栏：

- 算 12 / 22 / 32；
- 三门具；
- 五将发；
- 从开 / 休 / 生三吉门出。

## JF4M-06 陈兵向背

福应经方向表固定：

- 1 西北
- 2 正南
- 3 东北
- 4 正东
- 6 正西
- 7 西南
- 8 正北
- 9 东南

5 不定义。

不得与 J4M-06 的 1/2/4/5/6/9 阵旗表互补。

## JF4M-07 置阵随地

当前可稳定机器化：

- 水曲
- 火锐
- 木直
- 金方
- 土圆
- 主客阵形五行相制取胜负

当前卷四转录已锁定五类地形：

- 后高前低 → 锐阵；
- 前高后低 → 直阵；
- 地形跨斜 → 圆阵；
- 地形高而不平 → 方阵；
- 左右势高岗 → 曲阵。

runtime 直接使用本来源地形表；不借 J4M-07 地形表填空。

## JF4M-08 随地形制变

保留本来源自身读法：

- 地形 / 卒习服 / 器用为急；
- 步兵地：车骑二不当一；
- 萑苇竹萧：矛鋋类，长戟二不当一；
- 曲道：剑楯类；
- 不习服：百不当十；
- 将不省兵：五不当一。

这些不得被 J4M-08 的三不当一、百不当一、十不当一覆盖。

## JF4M-09 太乙天外地内

地内助主：

1 / 8 / 3 / 4

天外助客：

9 / 2 / 7 / 6

一宫是本来源最关键的 source variant；不得改成 J4M-09 的“一宫未定义”。

门具 / 将发继续作为决胜 readiness 分栏。

## JF4M-10 风云飞鸟

当前卷四转录已锁定并实现：

- 风云飞鸟冲格迫击太乙宫 -> 大败；
- 迫击客大将 -> 客败；
- 迫击主将 -> 主败；
- 从主人刑上来 -> 主败；
- 从客刑上来 -> 客败；
- 从主目击客大将 -> 客败；
- 从客目击主大将 -> 主败；
- 从太岁 / 太阴 / 月建击主人阵 -> 主败；
- 从太岁 / 太阴 / 月建击客阵 -> 客败；
- 翼主人阵前 -> 主胜；
- 翼客阵前 -> 客胜；
- 回旋风起、飞鸟旋阵或旗竿折 -> 大败之兆；
- 众鸟翼噪并风云冲阵 -> 凶，并按所冲主/客阵定败方。

source_profiles 现在允许 J4M-11 与 JF4M-10 并列保存，但 cross_source_merge=false。

## JF4M-11 奇伏

固定：

- 奇兵三成；
- 奇兵必从大杀之地；
- 大杀 = 天目所临之下；
- 转录另记居高、去敌三五里；
- 11 / 21 / 31 伏藏；
- 掩迫时发；
- 贼近则伏要害。

不得引入 J4M-10 的 12 / 22 / 32 伏兵时，也不得把“大杀”句改成金镜“大煞”句。
