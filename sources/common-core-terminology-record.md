# 公共 canonical 术语层记录

## 目标

把七术 T7、八占 D8 共同使用的坐标、神名、五行与气势概念集中到单一术语目录，避免各模块重复维护。

稳定入口：

- `terminology/common-core.json`
- runtime: `src/kintaiyi/taiyi_rules.py`
- machine rule summary: `rules/taiyi_v1.json`

### 吕申加位

统一为十六环顺行四格。

吕申寅 -> 大神巳。

中五不得进入该变换。

### 五态

统一由五行生克生成：

- 同类 -> 旺 / 比和
- 环境生主体 -> 相 / 生我
- 环境克主体 -> 死 / 克我
- 主体克环境 -> 囚 / 我克
- 主体生环境 -> 休 / 我生

不维护第二套手抄五态表。

### 大神火十二长生

寅长生、卯沐浴、辰冠带、巳临官、午帝旺、未衰、申病、酉死、戌墓、亥绝、子胎、丑养。

艮、巽、坤、乾没有支位十二长生值。

十二长生与五态是两层事实；墓不等于废。

### 固有五行 / 所在宫五行

固有五行：

- 太乙木
- 始击火
- 文昌土
- 主大将金
- 主参将水
- 客大将水
- 客参将木

七术 Mode B 用将实际所在九宫五行作为主体，不用固有五行。

因此对象模型应同时允许：

- `intrinsic_element`
- `palace_element`

两者不得互相覆盖。
