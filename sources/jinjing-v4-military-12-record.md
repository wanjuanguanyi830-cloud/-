## J4M-01 三门

正文三门为开、休、生。

只实现正文直接覆盖的门具组合：

- 太乙、天目分临开/生二门 → 两门不具
- 太乙或天目临休门 → 三门不具

同落开、同落生、只给一端等未展开组合不自行类推。

直门另按正文：

- 240 为一周
- 每 30 移一门
- 开 → 休 → 生 → 伤 → 杜 → 景 → 死 → 惊

州郡岁计直门吉凶：

- 开/休/生：大吉
- 景：小吉
- 死/惊/伤/杜：大凶

门具与直门吉凶分栏。

## J4M-02 五将

五将阻断条件：

- 始击有掩击
- 文昌有囚迫
- 主客大小将有相关

三门具/不具是 J4M-01 上游事实，不和五将本体混成一个旧式字符串。

保留正文边界：

- 三门不具 → 不可出兵
- 五将不发 → 不可临战

## J4M-03 主客相关法：partial 的理由

正文能直接确定：

- 客目五行克主目五行 → 客关得主人 → 客胜
- 主目五行克客目五行 → 主人关得客 → 主胜

正文同时写“皆用日计纳音以决之”，但卷四本段没有继续展开：

- 日计纳音与主目/客目五行如何组合
- 纳音是在定“关”的名称、加权胜负，还是另作门槛
- 出现比和、生我、我生时应如何处理

核对维基文库、识典及其他《金镜》转录后，仍只见同一句，没有找到进一步公式。

因此：

- `day_nayin_element` 只作为显式来源字段保留
- `fully_computable=False`
- 不用旧代码反推 canonical

### 旧 `wc_n_sj` 必须隔离

旧参考实现额外做了：

- 日计纳音等于主目五行 → 标“主关”
- 日计纳音等于客目五行 → 标“客关”
- 主将是否与太乙同宫 → 改写主客胜负
- 比和/生我/我生 → 直接给“和”

这些规则均未见卷四本段明文，故只记作 legacy inference，不进入 J4M-03 canonical。

## J4M-04 推主客：已完整 source-specific
