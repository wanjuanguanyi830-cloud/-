# 《太乙金镜式经》卷四军事十二法整理记录

## 结论

本次用户列出的十二条，应作为 **四库本《太乙金镜式经》卷四连续军事法** 单独建档，不应直接并入现有 C8 的 `volume5_strict` 来源层。

现有 C8 的目标是拆解旧 `junshi_zhanlue` 混合函数；本记录新增的是来源目录与 crosswalk。两者职责不同：

- C8：组合层边界，防止八占、三门五将、主客动静、将帅贤否互相覆盖。
- J4M：四库本《金镜》卷四十二法的来源顺序、标题异文、依赖与实现状态。

机器可读规则见 `rules/jinjing_v4_military.json`。

## 与 C8 的核对结果

### 已有但只覆盖部分语义

**J4M-01 / J4M-02 三门五将**

C8-L2 目前只归一化上游“三门具/不具、五将发/不发”事实，不重算公式。这一边界是正确的，但不能标记为 J4M 已实现。后续需要按《金镜》卷四单独实现直门、太乙/天目与门具关系，以及始击/文昌/主客大小将条件。

**J4M-04 推主客**

C8-L3 已正确保存两条角色规则：

- 陈兵原野：先动为客，后应为主。
- 安居之势：先动为主，后至为客。

但《金镜》正文还把三门、五将、阴阳和不和以及主客出入神一起放在本法中。C8 当前只实现“角色/动静”子层，故状态为 partial，不得称整条 J4M-04 已完成。

### 当前缺少独立层

J4M-03、05、06、07、08、09、10、11、12 当前均没有《金镜》卷四 source-specific canonical 实现。

尤其：

- **J4M-03 推主客相关法** 是五行相制/关法；不得并入 J4M-04 的先后动静。
- **J4M-05 推出师法** 以算十二/二十二/三十二、门具、将发、三吉门为条件；不得拿《统宗》卷五“人君出师略地”的兵车/甲士/步卒数量表代替。
- **J4M-06 推陈兵向背** 是按算数决定向背、阵型、旗色；不得拿旧项目卷十五“陈兵出乡”替代。
- **J4M-07 推制阵随地法** 与 **J4M-08 推随地制变** 相邻但不同：前者重阵形—五行—地势，后者重兵种/器械/训练随地应变。

## J4M-09 的来源冲突必须隔离

这里发现现库此前最容易再次混法的一处。

四库本《太乙金镜式经》卷四正文写作：

- 八、三、四：地内，助主。
- 九、二、七、六：天外，助客。
- 一宫在这段文字中没有列入地内组。

而《太乙统宗宝鉴》卷五同名术写作：

- 一、八、三、四：天内，助主。
- 九、二、七、六：天外，助客。

旧 `kentang2017/kintaiyi` 的 `ty_gong_dist` 采用的是后者 `[1,8,3,4]`。因此不能再把旧函数结果反写成《金镜》卷四 canonical。

本次规则表将两者保存为：

- `jinjing_siku_volume4` canonical：`[8,3,4]`
- `tongzong_volume5` source variant：`[1,8,3,4]`

一宫差异必须保留为来源异文/体系差异，待影印本进一步校勘，不自动“修正”为任一方。

## 旧参考实现只作线索

外部参考仓库 `kentang2017/kintaiyi` 可用于定位历史函数名，但不作为真源。此次核对发现：

- `threedoors` 只检查太乙所值八门，未体现《金镜》正文同时提到天目，不能直接升格。
- `fivegenerals` 把格局字符串与将居中五组合成结果，需重新按来源拆解。
- `wc_n_sj` 对应 J4M-03，但实现细节须重新核对“日计纳音”，不可直接搬运。
- `flybird_wl` 对应 J4M-11 的一部分，但只覆盖若干宫位分支，不能视为完整正文。
- 旧卷十五 `qibing_fubing` / `suidi_zhibian` 与《金镜》卷四存在内容重叠，但来源卷次不同，必须保留 source profile。

## 下一实现顺序

建议按依赖从低到高推进：

1. J4M-06 陈兵向背：纯算数查表，最适合先落成。
2. J4M-07 制阵随地：地形→阵型→五行，可独立实现。
3. J4M-09 天外地内：先做 source-specific profile，明确一宫差异。
4. J4M-05 出师：复用 J4M-01/02 的上游事实。
5. J4M-10 奇伏：依赖算数、天目、掩迫、地形。
6. J4M-03 主客相关：需先统一主/客目五行与日计纳音输入。
7. J4M-11/12：需设计“外部观测事实”模型，不能从盘内字段伪造风云飞鸟/云气观测。

- J4M-03 与 J4M-04 永不合并。
- J4M-07 与 J4M-08 永不合并。
