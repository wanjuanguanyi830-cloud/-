## J4M-05 推出师法

《金镜》本条同时明确：

- 算十二、二十二、三十二；
- 五将发；
- 三门具；
- 出军从开、休、生三吉门。

本条开头“行师必出奇门，略地并用其二”，后文又有“二奇门”式压缩，字面容易误解为“两扇奇门”。

《太乙统宗宝鉴》卷五同段把句义拆开：

- “出其门” -> 出开、休、生三吉门；
- “用其二” -> 算得二之数。

因此 J4M-05 继续把两个条件独立建模：

1. calculation condition：12 / 22 / 32；
2. exit-gate condition：开 / 休 / 生。

《统宗》的兵额、离宫大威等扩展只作参校，不写入 J4M-05。

## J4M-06 推陈兵向背

《金镜》正文明确列：

- 1
- 2
- 4
- 5
- 6
- 9

每项同时包含：

- 出军方向；
- 战利方向；
- 所背地形；
- 阵形；
- 旗色。

《统宗》后部另有“陈兵必出其乡”，其结构主要是“算 -> 出向”，并列出 1/2/3/4/6/7/8/9 等。

二者近名但不是同一规则。

固定边界：

- 不以《统宗》3/7/8补《金镜》；
- 不以《金镜》5及阵形、旗色反写《统宗》；
- J4M-06 不自动对任意算数取个位。

## J4M-07 推制阵随地法

《金镜》原文明列五阵五行：

- 曲阵 = 水
- 锐阵 = 火
- 直阵 = 木
- 方阵 = 金
- 圆阵 = 土

并明确两层规则：

### A. 地形制阵

- 后高前下 -> 锐阵
- 前高后下 -> 直阵
- 地洿邪 -> 圆阵
- 地高而平 -> 方阵
- 左右势高 -> 曲阵

另有“地顺其向则吉，地反其向则凶”。

### B. 主客阵形五行胜负

原文明确：

“皆取主客置阵，次以五行相克而取胜负。”

此前 runtime 只实现 A，没有真正实现 B，因此虽标为 complete，实际缺一层 canonical 逻辑。

C72 已补：

- 主阵五行克客阵 -> 主胜；
- 客阵五行克主阵 -> 客胜；
- 同五行或相生 -> 本条没有明确相克胜负，不补断。

此修正只补《金镜》明文，不使用现代战力评分。
