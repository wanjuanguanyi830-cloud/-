# 时计阴阳profile与八门直使整合记录

## 规则标识

- `CORE-TIME-COUNT-PROFILE`
- `CORE-TIME-PROFILE-CONTRACT`
- runtime: `kintaiyi.taiyi_time_profile`

## 阴阳局

《统宗》卷一四计三条相互校验：

- 太乙所在：唯时夏至后用阴局；
- 文昌天目：唯时计夏至后用阴局；
- 计神：惟夏至后用阴局。

因此：

- 冬至后时计 -> 阳局；
- 夏至后时计 -> 阴局。

## 八门直使

《金镜》卷一“推八门用法”“推冬至加时所直门法”“推夏至加时所直门法”：

阳遁四门：

`开 -> 生 -> 惊 -> 休`

阴遁四门：

`杜 -> 死 -> 伤 -> 景`

每30时一移。

该部分复用现有C119 runtime，不重新写一套八门公式。

## 为什么保留两个数值输入

四计共同核心使用：

`entry_count`

它是“入局积数”，进入72/24/18/12等周期。

C119八门直使使用：

`duty_time_real`

它来自冬至/夏至加时的“时实”，进入240/120/30门周期。

虽然二者都与冬夏至以来的时间累积相关，但原文计算链和余数处理不同。

因此本整合层不做：

`entry_count == duty_time_real`

的现代简化。

等历法上游完整实现后，再由上游同时提供两个经过各自公式校定的量。

## 日历边界

本层不通过公历月份判断阴阳遁。

必须由上游明确告诉：

- 所求时属于冬至后半岁；
- 或属于夏至后半岁。

边界最终应使用实际冬至/夏至气应时刻，而不是固定6月/12月某日。
