## 1. 九段不是累计阈值

- 106

总和恰为：

`4560`

因此它们必须先累计成边界：

- 1–106
- 107–480
- 481–960
- 961–1680
- 1681–2400
- 2401–3000
- 3001–3600
- 3601–4080
- 4081–4560

旧 `guiyun.yinyang_jiu_e` 直接拿每段长度与余数逐项比较，第二段起即错位。

固定：

`canonical_equivalent=False`

## 3. 702 / 720 异文

部分在线 OCR 见第四段“七百二年”，另见证作“七百二十年”。

若取 702，九段总长仅 4542；
取 720 则正合全文一元 4560。

因此：

- 保留 702 / 720 witness；
- runtime 正规化为 720；
- 状态：`ocr_corrected_by_parallel_witness_and_internal_arithmetic`。

## 4. 第四段阴阳字

在线 OCR 有“四阳七灾水七年”。

但全术明确：

- 五阳主旱；
- 四阴主水；
- 九会阴阳交错。

因此正规化：

`四阴七灾水七年`

并保留原 witness。

## 5. 第九段 3 / 5 年冲突

在线 OCR 有：

`九阳三灾旱五年`

但：

- 名称本身为“三灾”；
- 全篇说灾年共57；
- 若取3，总和为57；
- 若取5，总和为59。

因此 runtime 取3，并保留“旱五年”OCR witness。

## 6. runtime

新增：

`src/kintaiyi/yinyang_nine_calamities.py`

规则：

`C46-YJ-9E`

使用：

`(accumulated_year + 130) mod 4560`

余0正规化为一元第4560年，而不是下一元第0年。

灾期定义为每段末尾对应的 9 / 7 / 5 / 3 年。

## 7. 边界

C46 是独立周期规则，不代表整个旧“卷九”综合 wrapper 已迁移。

不得恢复旧阈值算法。
