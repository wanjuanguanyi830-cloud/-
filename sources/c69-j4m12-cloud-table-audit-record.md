# C69 J4M-12 云气表逐项审计与去对称推补

日期：2026-10-05

## 问题来源

J4M-12 “推阵有风云气定胜负”此前虽然已经做到：

- 方位×颜色按正文表；
- 未列颜色不以五行补齐；
- 区分云气在敌阵/我阵；

但仍残留两处“程序比原文说得更多”的问题。

## 一、西方白云被错误补成“大胜”

四库本正文：

“假令敌在西方，有白云气在敌阵上，庚辛日弥佳。”

本句没有明写：

- 大胜；
- 胜；
- 敌大胜。

旧 runtime 因为北黑、南赤、东青都有“大胜”，按五行/表格对称性把西白补成：

base_verdict = 大胜
qi_class = 胜气

这不符合“原文未明则不补”的仓库政策。

### C69 修正

西方白云现在：

- base_verdict = null
- effective_verdict = null
- qi_class = 基础胜负未明
- 庚/辛日仍可返回 day_modifier = 弥佳
- source_note 明确说明本句没有写基础胜负

不得再用五行配方位或四方对称性补“大胜”。

## 二、“云气所在阵”不等于“断语主体”

正文大部分例句以“敌阵上”展开，例如：

- 敌大胜
- 敌欲罢阵求和
- 敌将迟钝
- 敌败

但北方红云一条明确写：

“若红云气在敌阵上，客胜。”

这里的主体是“客”，不是泛指“云气所在的敌阵”。

后文又说：

“此诸云气在敌阵上既然，若在我阵上亦尔。”

这允许同一方位×颜色条目用于我阵，但不能据此把每个明确的“主/客”词机械换成“我/敌”。

### C69 修正

runtime 分成：

- cloud_bearer：云气实际在“敌”阵还是“我”阵
- subject_mode：
  - formation
  - formation_general
  - guest_role
- verdict_subject：断语真正主体

例如北方红云：

无论 cloud_bearer 是敌还是我：

- base_verdict = 客胜
- verdict_subject = 客
- subject_mode = guest_role

不再返回“我胜/敌胜”。

## 三、保持不变

以下规则不变：

- 北黑、南赤、东青等正文明确“大胜”的条目照录；
- 正文明确“大败/败/失利/求和/迟钝”的条目照录；
- 未列颜色保持 not_defined_by_source_passage；
- 胜气断续不次或南北溃乱 -> 败；
- 败气断续溃乱 -> 不至全恶；
- 胜气在大将/参将上的修正规则保留；
- 无云气 -> 不强判胜负。

## 四、原则

J4M-12 从此固定：

1. 不以五行常识补表；
2. 不以四方颜色对称性补表；
3. 不因“若在我阵上亦尔”而机械改写明确的主/客角色词；
4. 云气位置与断语主体分栏。
