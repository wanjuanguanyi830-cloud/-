# C68 《太乙统宗宝鉴》五福吉算所利术

日期：2026-10-05

## 1. 范围

C68 只解释“五福吉算”正文已经得到的：

`不满宫法所余`

即 1..45 的宫内余数，映射到“所利”对象。

唯一 runtime：

`src/kintaiyi/wufu_auspicious_numbers.py`

rule id：

`C68-WUFU-AUSPICIOUS-NUMBER`

C68 不从积年自动计算五福位置，也不调用 C67。

## 2. 直接见证

《太乙统宗宝鉴》两个直接见证互校：

### NGJ

题：

`明五福吉算所利术`

写：

- 225年一周；
- 45年一宫；
- 不满一宫法所余者，方知五福所利。

数列虽有 OCR 连字，但十组均可辨。

### CADAL

同题 / 近题见证：

- 225年一周；
- 45年行一宫；
- 数列与 NGJ 同结构。

两见证互校后足以锁定 1..45 每个整数的归属。

## 4. 为什么不写成“取个位公式”

十组表面上有明显个位规律。

但 C68 不以：

`remainder % 10`

作为来源公式。

原因：

- 原文是逐组列数；
- 45 是民组最后一项；
- 师帅以后没有 46/47/48/49/50；
- 若只按个位机械延伸，会凭空制造原文范围外条目。

因此 runtime 保存完整显式表，并测试：

- 1..45 正好覆盖；
- 46..50 必须拒绝。

## 5. 与 C67 的边界

C67 管五福位置，并且来源 profile 不同：

- 统宗：+115 / 2250 → 225 / 45；
- 金镜：无该盈差 / 225 / 45。

C68 不决定使用哪一套位置公式。

固定：

- `auto_position_lookup_used=False`
- `auto_remainder_from_accumulated_count_used=False`
- 输入只接受显式 `remainder=1..45`。

调用方若要把 C67 与 C68 组合，必须在上游明确：

1. 先选位置 source profile；
2. 得到/确认宫法余数；
3. 再显式送入 C68。

## 6. 225 / 250 周期异文

统宗两个直接见证：

`225年一周`

后期《太白兵备统宗宝鉴》等见证出现：

`250年一周`

并伴随另一套五福位置盈差文本。

C68 不选择 250。

固定：

- `later_250_cycle.status=source_variant_not_applied`
- `canonical_selected=None`

因为 C68 的职责只是解释 1..45 宫内余数，周期冲突不应污染已经可核的十组数表。

## 7. C15 状态

`明五福吉算所主術`

现 action：

`use_c68_wufu_auspicious_number_runtime`

仍：

`migrate_whole=False`

原因：

旧 flat 字段可能同时携带五福位置、同宫断语和吉算解释；C67/C68 已将其职责拆开。
