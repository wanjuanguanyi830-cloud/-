# C69B 《金镜》卷一“推太乙当时法”六壬叠盘

日期：2026-10-05

## 1. 为什么作为 C69B

本项不是另起一套太乙规则，而是补 C69 原来明确缺失的：

- 日度加时；
- 六壬式安天乙前后诸将。

因此使用 C69B，不占当前并行 J4M 校勘正在连续使用的 C12x 编号。

## 2. 《金镜》直接桥接文字

卷一先说：

> 算日在何宿，计属何辰，以时加位，立贵前后，以论将之吉凶。

“推太乙当时法”又说：

> 更以日度加时，因步六壬式，知天乙成败之分。

因此程序链固定为：

1. C118 求某节气第N日所在宿；
2. 由十二分野求该宿所属地支；
3. 该支作为本条“日度加时”的六壬月将等价支；
4. 月将加占时支；
5. C69 按日干 + 朝/暮取天乙贵人治神；
6. 求该贵人天盘支落到地盘何支；
7. 依六壬式确定顺逆；
8. 排天乙贵神、前五、后六十二天将。

## 3. 十二天将次序

《金镜》C69 自身已经直接给相对关系：

- 贵神
- 前一螣蛇
- 前二朱雀
- 前三六合
- 前四勾陈
- 前五青龙
- 后一天后
- 后二太阴
- 后三玄武
- 后四太常
- 后五白虎
- 后六天空

换成环状顺序即：

`贵 → 蛇 → 雀 → 合 → 勾 → 龙 → 空 → 虎 → 常 → 玄 → 阴 → 后`

这与《六壬大全》的十二天将序一致。

《六壬大全》只在这里作为《金镜》明确写“因步六壬式”后的程序参校，
不把四课、三传等其他六壬术内容混入太乙。

## 4. 月将加时

C69B：

`heaven_plate(month_general_branch, hour_branch)`

规则：

- 地盘十二支固定；
- 把日宿分野支加在占时支上；
- 其余天盘支顺排。

例如：

- 立冬第6日：C118 得心宿；
- 心宿属宋 / 豫州 / 卯；
- 卯加寅；
- 地盘寅上天盘卯；
- 地盘子上天盘丑。

## 5. 庚日朝贵

C69 直接表：

- 戊、庚日与甲日反；
- 庚日朝治大吉；
- 大吉 = 丑。

在上例天地盘中：

- 天盘丑落地盘子；
- 贵人落子。

六壬顺逆：

- 贵人落亥、子、丑、寅、卯、辰侧 → 顺；
- 落巳、午、未、申、酉、戌侧 → 逆。

故本例顺布。

## 6. 《金镜》实例回归

原例：

- 十月五日庚申；
- 时加戊寅；
- 立冬气；
- 第六纪；
- 太乙九宫；
- 主大将九宫；
- 主参将七宫；
- 客大将四宫；
- 客参将二宫；
- 立冬六日，日在心宿；
- 庚日天乙朝治大吉。

C69B 复算十二天将：

- 巳 → 青龙
- 申 → 太常
- 卯 → 六合
- 午 → 天空

九宫转六壬地支 adapter：

- 9 → 巳
- 7 → 申
- 4 → 卯
- 2 → 午

因此得到：

- 太乙九宫 → 青龙；
- 主大将九宫 → 青龙；
- 主参将七宫 → 太常；
- 客大将四宫 → 六合；
- 客参将二宫 → 天空。

前四项与公开转录逐项一致。

最后一项公开转录作：

`天定下`

但按本条六壬式复算与二宫午位均落：

`天空`

C69B 处理：

- source_transcription = 天定
- computed_general = 天空
- 不把“天定”删除，也不反过来为了迎合 OCR 修改六壬排式。

这应继续等待影印字形核定。

## 7. 九宫→十二支 adapter

六壬盘只接受十二支，太乙九宫含四维卦位。

C69B 使用：

- 1乾 → 亥
- 2离 → 午
- 3艮 → 寅
- 4震 → 卯
- 6兑 → 酉
- 7坤 → 申
- 8坎 → 子
- 9巽 → 巳

该层明确标：

`derived_bagua_branch_projection`

且：

`projection_lossy=True`

不替换太乙十六宫原坐标。

《金镜》本例直接验证其中：

- 9→巳
- 7→申
- 4→卯
- 2→午

中五：

- 无十二支投影；
- 返回 `center_unprojectable`。

严格调用方也可直接传 `entity_branches`，绕过这一 adapter。

## 8. 当前完整度

现在已经可执行：

`节气第N日 → 宿 → 分野支 → 加时 → 贵人落地 → 顺逆 → 十二天将 → 实体所临天将`

但 C69 仍不改为完全自动日期公式，因为仍有三个入口边界：

1. 公历日期 → 节气第几日仍由上游历法提供；
2. 朝/暮仍须显式给定，尚未在 C69 自行划分；
3. 九宫→十二支是有损 adapter；调用方可选择直接提供精确地支。

因此：

`complete_current_time_formula=False`

但原来的“日度加时 / 六壬安将”两项核心缺口已经由 C69B 实质补齐。
