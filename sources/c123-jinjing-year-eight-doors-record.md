# C123 《金镜》卷一“推八门占岁计法”

日期：2026-10-05

## 1. 直接来源

《太乙金镜式经》卷一“推八门占岁计法”。

直接公式：

1. 置上元甲子以来距所求积年；
2. 以720去之；
3. 不尽再以240除之；
4. 余以30约之，为直门数；
5. 不尽为直门所入年；
6. 起开门，依次休、生，左行八门，周而复始。

八门次序按本段及现行八门体系：

- 开
- 休
- 生
- 伤
- 杜
- 景
- 死
- 惊

直接见证：

- https://zh.wikisource.org/zh-hans/太乙金鏡式經_(四庫全書本)/卷01
- https://www.shidianguji.com/book/SK1615/chapter/1l9lir739kc96

## 2. 周期

固定：

- 外周期720年；
- 内周期240年；
- 每门30年。

C123 用1-based积年：

`remainder_720 = n % 720 or 720`

`remainder_240 = remainder_720 % 240 or 240`

`door_index = (remainder_240 - 1) // 30`

`year_in_door = (remainder_240 - 1) % 30 + 1`

## 3. 开元十二年例

卷一前文给：

- 上元至开元十二年甲子：1937281算。

代入：

- 1937281 mod720 = 481；
- 481 mod240 = 1；
- 开门第1年。

三十年后：

- 内余31；
- 休门第1年。

与正文“甲子开门为直使，至第三十一年甲午休门为直使”的30年移门逻辑相合。

这里“第三十一年”理解为以甲子当前年作第1年，至甲午共跨30年；
不把它误读成唐玄宗开元三十一年年号。

## 4. 与 C119 分层

C119：

- 时计八门；
- 30时一门；
- 阳遁开生惊休；
- 阴遁杜死伤景。

C123：

- 岁计八门；
- 30年一门；
- 八门完整循环。

两者不可互换。
