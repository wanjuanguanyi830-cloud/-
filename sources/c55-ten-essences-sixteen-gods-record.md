## 3. 天皇

《太乙统宗宝鉴》卷十八 / 卷二十主见证：

- 命起武德；
- 顺行十六宫间之神；
- 遇阴德、和德、大炅、大武四维之地重留一算；
- 阴局取阳局对冲。

因此阳局 20 步：

`武德 → 太簇 → 阴主 → 阴德 → 阴德 → 大义 → 地主 → 阳德 → 和德 → 和德 → 吕申 → 高丛 → 太阳 → 大炅 → 大炅 → 大神 → 大威 → 天道 → 大武 → 大武`

四处重留：

- 阴德 / 乾；
- 和德 / 艮；
- 大炅 / 巽；
- 大武 / 坤。

阴局不另造无来源表，而是逐步取阳局对冲。

《武经总要》另见阴起吕申逆行的读法，作为 source variant 保存，不覆盖统宗主 profile。

## 4. 帝符

统宗主见证：

- 命起阴主；
- 顺行十六宫间之神；
- 遇地主、高丛、大威、太簇四正之地重留一算；
- 阴局取阳局对冲。

阳局 20 步：

`阴主 → 阴德 → 大义 → 地主 → 地主 → 阳德 → 和德 → 吕申 → 高丛 → 高丛 → 太阳 → 大炅 → 大神 → 大威 → 大威 → 天道 → 大武 → 武德 → 太簇 → 太簇`

四处重留实际是四处，不是八处：

- 地主 / 子；
- 高丛 / 卯；
- 大威 / 午；
- 太簇 / 酉。

旧来源骨架一度把“四神名 + 四宫名”并列成八项；C55 已拆成 `repeat_on_gods` 与 `repeat_on_positions`，明确二者是一一对应的同四处。

《武经总要》另见阴起太阳逆行的读法，只作参校异文。

## 5. 帝符盈差 17 / 70

统宗不同见证 / OCR 存在：

- 卷十八：17；
- 另一见证：70。

但同条正文明确诸家经旨无所加之术，依古法不取。

因此 C55 固定：

- 同时保存 17 / 70 为 witness variant；
- `apply=False`；
- 两值均不进入位置 runtime。

天皇 +14 同样被正文否定，不应用。
