# C117 《金镜》卷一“推太公考时法”

日期：2026-10-05

## 1. 直接正文条件

《太乙金镜式经》卷一直接列：

- 右太乙、左天目；
- 阴阳和顺；
- 上下无掩、击、迫、囚、关、格、对；
- 无四郭固/杜；
- 不提挟；
- 太乙不在阳绝之地；
- 神将独立；
- 吉道清虚；
- 三门具、五将发，则利以行兵；
- 又合玄命，王相挟和；
- 玄命临旺相之乡，上下相生；
- 直使前三五、后二四合者大吉。

直接见证：

- https://www.shidianguji.com/book/SK1615/chapter/1l9lir739jabu
- https://zh.wikisource.org/zh-hans/太乙金鏡式經_(四庫全書本)/卷01

## 2. 实现策略

新增：

- `src/kintaiyi/jinjing_taigong_timing.py`
- `tests/test_c117_jinjing_taigong_timing.py`

C117 不重算任何上游规则。

调用方必须显式提供：

- 是否“右太乙左天目”；
- 阴阳是否和顺；
- 当前阻碍格局列表（允许显式空列表）；
- 太乙是否在阳绝；
- 神将是否独立；
- 当前直门；
- 门下是否有凶恶之神；
- 三门是否具；
- 五将是否发。

玄命部分：

- 身份 -> 玄命对象由 C116 提供；
- 当前是否确实临玄命对象必须显式输入；
- 旺相必须显式输入；
- 上下相生必须显式输入。

## 3. 吉道清虚

原文自释：

- 吉道 = 开 / 休 / 生；
- 清虚 = 门无凶恶之神。

因此 C117 只把这三门视为吉道。

其余门并不因为其他模块可能有吉义而在本条自动改判。

## 4. 出兵有利

只有所有基础条件都显式齐全时，C117 才给：

`military_action_favorable=True/False`

任一条件缺失：

`None`

而不是把“未知”当“不利”。

## 5. 玄命合

原文例：

天子玄命在天乙，临旺相之乡，上下相生，故曰合。

C117 因此要求三项：

1. 当前所临对象 = C116 对应玄命；
2. 旺相；
3. 上下相生。

三者齐全才给：

`xuanming_harmony=True`

## 6. “直使前三五、后二四”边界

当前正文句：

`门与玄命上天乙直使前三五后二四合者大吉`

结构存在解释空间。

C117 固定：

- 不自动拆为数位公式；
- `auto_computation=False`
- 由调用方显式给 `direct_envoy_clause_matched=True/False/None`。

只有：

- 出兵基础条件有利；
- 玄命合；
- 直使条件显式匹配；

三者同时成立才给：

`greatly_auspicious=True`

这为后续直使 / 八门 C118+ 校勘保留接口，不提前锁死。
