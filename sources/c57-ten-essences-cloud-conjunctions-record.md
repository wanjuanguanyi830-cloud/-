# C57 十精太乙云气：显式合会断语

日期：2026-10-05

## 直接来源

《太乙统宗宝鉴》“明十精太乙所主术”各十精条下的合会断语，以及“明十精太乙云气所主术”总括。

当前见证有卷十八 / 卷二十编次差异；项目只保存 witness volume variant，不复制算法。

独立参校：

- 《武经总要》十精与太乙 / 诸神合会条；
- 《三才世纬》相关十精云气转录。

## 1. 本层只解释显式合会

唯一 runtime：

`src/kintaiyi/ten_essences_cloud_omens.py`

rule id：

`C57-TEN-ESSENCE-CLOUD-CONJUNCTION`

C57 不从 C53/C55/C56 落宫自动判断“合”。

调用方必须显式提供：

- `conjunctions`
- 必要时 `taiyi_qi_state`
- 必要时 `taiyi_palace_yinyang`
- 必要时 `essence_palace`

无合会也必须显式传空 list。

固定：

- `auto_position_lookup_used=False`
- `j4m11_external_observation_used=False`

## 2. 十精飞鸟与军事飞鸟严格分离

C57 的“飞鸟”是十精推步神位。

J4M-11 的“飞鸟”是真实外部观测。

不得用十精飞鸟落宫替代 J4M-11 的飞鸟观测，也不得反向使用 J4M-11 观测作为十精位置。

## 3. 旺相 / 非旺相必须显式

示例：

- 帝符合太乙：日晕、大风；
- 若又明确旺相：再加小雨、小阴云、疾风卒起；
- 飞鸟合太乙且旺相：天星有变；
- 飞鸟合太乙且非旺相 / 休囚：大风；
- 八风合太乙且旺相：云起、小雨。

如果规则要求旺相状态而调用方未给，则保持 partial，不猜。

## 4. 阴阳宫必须显式

八风合太乙：

- 阴宫 → 雨；
- 阳宫 → 风。

调用方若只声明“八风合太乙”，却未给阴阳宫，则只命中不依赖阴阳宫的规则，不自行从宫号推阴阳。

## 5. 宫位直断另列

当前直接正文另有：

太尊：

- 8宫 → 日晕；
- 6宫 → 阴昏；
- 2宫 → 太阴昏寒；
- 4宫 → 日晕。

飞鸟：

- 9宫 / 6宫 → 日晕。

这些作为 `PALACE_RULES` 并列保存，不混成“合太乙”规则。

## 6. 见证异文不静默统一

当前保留：

### 天皇合飞鸟

- 统宗：有阴雨；
- 武经总要：小阴雨。

只正规化为“阴雨”，原文字样并存。

### 天皇合天时

- 统宗：阴昏；
- 武经总要：小昏。

固定：

`source_variant_unresolved`

不选一条覆盖另一条。

### 三风合天时

- 统宗：小阴雨；
- 武经总要：小阴风。

固定：

`source_variant_unresolved`

### 五行 / 八风与帝符

统宗在线见“地符”，武经总要见“帝符”。

C52 已确认十精 canonical 名称为“帝符”，所以这里只做名称层正规化，并保留 witness variant，不把“地符”提升为独立十精。

## 7. 张良总括句不覆盖逐条断语

统宗在线见证总括句 OCR 近似：

- 帝符、太尊、天时、五风、八风、三风与太乙合；
- 阳宫“暗”；
- 阴宫雨。

《三才世纬》参校则见：

- 帝符、太尊、天时、五行、八风、五风、三风；
- 阳宫晴旱；
- 阴宫雨水。

两处存在：

- “暗 / 晴旱”差异；
- “五行是否列入”差异。

因此：

- `canonical_selected=None`
- `runtime_applied=False`

逐条十精直接断语优先，不用总括句反写。

## 8. 延后层

C57 暂不实现：

- 太乙初移宫时的云色时变；
- 天气纯厚 / 薄；
- 黄雾 / 黑赤 / 青白等色象；
- 天旱取阳 / 天雨取阴；
- 旺相使变速的总括修饰；
- 太乙数 30 / 40 / 50 等天气断语。

这些属于 C58+。
