# C58 十精太乙云气：初移宫云色时变与天气观察层

日期：2026-10-05

## 直接来源

《太乙统宗宝鉴》“明十精太乙云气所主术”。

参校：

- 《太乙金镜式经》“推候十精太乙云气法”；
- 《武经总要》“推候十精太乙云气”；
- 《三才世纬》十精云气条。

## 1. 与 C51 / C57 分层

C51：

- 天子初登位日月旁云气。

C57：

- 十精 / 太乙 / 天目等显式合会断语。

C58：

- 太乙初移宫时真实云气观察；
- 云色 + 日时计数对应变发支时；
- 天气厚薄 / 色象；
- 旱雨取阴阳；
- 旺相使变疾速。

三层不得静默合并。

## 2. 观察窗口

日计：

- 只候太乙初移宫本日；
- 时段：日出、日午、日晡；
- 后二日不候。

时计：

- 只候初移宫本时；
- 后二时不占。

运行时要求显式：

- calculation_scope
- observation_slot
- move_offset

超出窗口只返回：

`outside_source_observation_window`

不推天气。

## 3. 云色 × 日时计数

统宗当前在线见证直接可读：

- 青 + 3/4 → 寅卯；
- 白 + 7/6 → 申酉；
- 黑 + 1/8 → 亥子。

赤色句在统宗当前在线 OCR / 图像转写层缺失，但《太乙金镜式经》《武经总要》一致见：

- 赤 + 9/2 → 巳午。

因此赤色固定：

`status=collation_supported_primary_online_gap`

不伪称统宗当前转写直接完整可见。

## 4. 旧白云时支错误隔离

旧 yunqi 表：

- 白 7/6 → 亥子。

直接见证与平行参校均支持：

- 白 7/6 → 申酉。

因此旧表：

`canonical_equivalent=False`

亥子属于黑 1/8。

## 5. 天气厚薄 / 色象

- 纯厚 → 雨；
- 华薄 → 风；
- 黄雾 → 晕；
- 黑赤 → 风；
- 青白 → 寒；
- 凝润 → 雾雨；
- 云气如扫 → 晴；
- 文彩轮囷萧索 → 大晴。

其中：

- 三才世纬“黑赤 → 风热”；
- “青白 → 风寒”。

C58 只固化平行见证稳定核心：

- 黑赤 → 风；
- 青白 → 寒；

并保存参校扩展，不覆盖主层。

## 6. 旱雨 / 旺相总括

显式天气背景：

- 旱 → 常以阳占；
- 雨 → 常以阴占。

显式 qi_state：

- 旺相 → 其变疾速。

不得由具体天气断语反推当前 qi_state。

## 7. 飞鸟合太乙风向异文

统宗 / 金镜当前见：

- 风从下来 / 风从其下来。

《武经总要》见：

- 风从其上来。

固定：

- `canonical_selected=None`
- `runtime_direction_applied=False`

C58 不输出单一风向。
