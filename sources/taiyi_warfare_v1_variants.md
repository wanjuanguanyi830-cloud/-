# 七术、八占来源与版本异文记录

本表记录本轮已确认的算法口径及尚待底本复核的文字差异。表中“待补”不代表规则已从其他版本补定。当前目标仓库收到的是规则层与回归样例；未取得本轮提及古籍的完整版次、页码和影像定位，故相关历史夹具明确标为定位不完整。

## 来源边界

| 规则 | 当前据以整理的来源 | 限制 |
|---|---|---|
| 太乙七术 | 《四库全书》本卷六七术条（篇题、版次、页码待补） | 保留卷六课例；不从单例推通用应期 |
| 八占三才／长短／五音／孤单／内外／多少／所主 | 卷六材料及《统宗宝鉴》相应规则（各条卷次、底本页码待补） | 两书内容并列作为 v1 采纳记录；未作版本源流研究 |
| 阴阳厄会 | 《统宗宝鉴》卷三与卷六对照（版次、页码待补） | 仅录已核对的一致阳阴宫组与奇偶条件 |
| 十六位／吕申加位／五行五态 | 本轮整理采用的共享规则 | 每个具体条文的逐字原文定位仍须补录 |

## 已确认规范

| 项目 | 规范处理 | 状态 |
|---|---|---|
| “帝王”／“帝旺” | 算法词表和输出统一用**帝旺**，火临午；原转录“帝王”仅放异文栏 | 用户已确认，锁定 |
| 五行状态 | 同类旺、环境生对象相、对象生环境休、对象克环境囚、环境克对象死 | v1 锁定 |
| 三才句读 | “一十、二十、三十、四十为无人”；即整十算数无“一” | v1 锁定 |
| 长短门槛 | 11以上长，10以下短 | v1 锁定 |
| 内外 | 八个固定内神与八个固定外神；不是按太乙宫临时分区 | v1 锁定 |
| 同算 | 基础比较只返回同数；卷六此条无明确平局断语 | 保持未决 |
| 狮子反掷应期 | “辛卯年破”只作为古例结果 | 不外推公式 |

## 古籍课例证据状态

目前可从前序整理复述的课例不等于已完成版本学核验。历史夹具保存规则编号、输入、已确认的中间结果、原书结果摘要和缺失书目信息；`原文引句` 暂为空。只有补齐书名／版本／卷篇／页码或影像坐标并复核引句后，才可把证据状态升级为“已核原文”。
