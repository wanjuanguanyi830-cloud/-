# C25 五音观风察将：风声与风向分层

## 校勘结论

旧参考函数允许：

- 显式 wind_sound；
- 或拿 V15-09 的风向五音结果反推风声类别。

C25 取消第二条。

原文〈明五音观风察将术〉描述的是**风声形态**：

- 宫风：沉厚隆隆，近车雷鼓声 → 将宽和有信
- 商风：清越铿然，近金石钟佩声 → 将威猛好杀
- 角风：肃习动林木 → 将仁恕、不易欺诈
- 徵风：急烈如奔马烈火 → 将猛烈难争锋
- 羽风：流动扬波如流水 → 将贪暴多奸诈

因此 V15-10 输入改为：

`wind_sound_class`

且固定：

`v15_09_direction_tone_substitute_allowed=False`

## 边界

- V15-09：风从哪个地支方向来，形成方向五音。
- V15-10：实际听到的风声属于哪一音。

两者都属于五音，但不是同一观测量。

V15-10 只描述将帅性情，不自动生成军事 winner。
