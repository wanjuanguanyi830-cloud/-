# G7 主客大将、参将来源记录

## 永久规则标识

- `CORE-G7-GENERALS`

## 《太乙金镜式经》卷二

“推太乙运式法”第七、八步明确：

- 置算之数以定主客大将之宫；
- 得十，置一；
- 得二十四，弃二十置四；
- 余皆以例而推。

因此《金镜》明确支持“算数决定大将、普通数去十取零”的基本骨架。

## 《太乙统宗宝鉴》卷二补全

《统宗》卷二把规则展开为：

- 单一至九；
- 十一至十九；
- 二十一至二十九；
- 三十一至三十九；

均“去十用零”，余数即主客大将宫。

若得：

- 10；
- 20；
- 30；
- 40；

则“以九去之”，所得余数为大将宫。

所以：

`10 -> 1`
`20 -> 2`
`30 -> 3`
`40 -> 4`

参将：

> 大将所得宫数三因之，仍去十用零。

故映射：

`1->3, 2->6, 3->9, 4->2, 5->5, 6->8, 7->1, 8->4, 9->7`

## 杜塞优先

《武经总要》《太乙秘书》等立成明确：

- 主/客算25时常直接记“八门杜”；
- “主/客大将、参将不出中宫”。

相关汇编又明列单五、十五、二十五、三十五为杜塞。

因此项目正式规定：

`5/15/25/35 -> blocked=True -> 大将=None -> 参将=None -> 五将不发`

字段 `nominal_center=5` 只保存“中五”语义，不代表存在正常可作用的五宫大将。

## 与旧实现的关系

旧参考代码的 `home_general()` / `away_general()` 不进入 canonical：

- 主整十旧分支把20/30/40错误压到1；
- 客整十旧分支常压到5；
- 另有“主算25改变客大将”特殊分支，缺本条直接原法依据。

旧函数仅保留 regression/quarantine 价值。

## 与三才层分离

`5/15/25/35` 的天地人算组成属于算结构层：

- 5：仅地；
- 15/25/35：天+地。

“杜塞、大小将不出”属于G7/军事状态层。

不得因为四数都触发杜塞，就把它们的三才组成合并成同一种结构。
