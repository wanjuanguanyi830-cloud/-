## V15-07 随地制变 / 置阵随地

直接结构化五类地形：

- 后高前下 → 锐阵 / 火；
- 前高后下 → 直阵 / 木；
- 左右势高 → 曲阵 / 水；
- 跨斜不便 → 圆阵 / 土；
- 地高广平 → 方阵 / 金。

主客阵形仍复用 V15-02 的算数→阵形结果。

只有五行明确相克时给主客胜方；同类或相生不扩断。

兵种地形表与阵形地形表分栏。

## V15-08 分合用兵

正文核心是军事期会程序：

1. 先定战地；
2. 定战时；
3. 移檄诸将；
4. 诸军按期会合；
5. 先期至者赏，后期至者罚；
6. 终以并力合战。

因此新 runtime 不再使用：

- 三门；
- 五将；
- 掩击关格；
- 主客大将同宫；
- 主客参将同宫。

这些属于旧 reference code 的跨层扩写，不是本条来源公式。

## V15-11 安营置阵

必须显式提供：

- 阴阳和顺；
- 上目格局检查：无掩/击/扶/格；
- 下目格局检查：无关/囚/迫/对；
- 太乙、上目、下目是否在阳绝；
- 三门是否具；
- 五将是否发。

任一明确不利则不宜；全部明确有利才判宜；有缺项则 not_computable。

不再按宫号数值大小推“二目在左/右”。

## V15-14 出兵军势胜负

本条改为纯外部军势/风云观察层。

可消费：

- 人马、旗鼓、上下和合等出军观察；
- 风从后/旁/逆来等现象；
- 天色、风雨、营幕、旗帜等异常；
- 风强云薄 / 云厚风弱的主客关系。

禁止：

- 用主客算长短替代军势观察；
- 从十精飞鸟位置自动生成风云飞鸟观察；
- 从 J4M-11 / J4M-12 自动借结果；
- 在没有任何观察时返回默认“必胜”。
