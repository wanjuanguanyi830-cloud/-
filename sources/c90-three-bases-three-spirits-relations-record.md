# C90 三基与天乙 / 地乙 / 直符同宫显式关系层

日期：2026-10-05

## 1. 范围

C90 迁《太乙统宗宝鉴》卷六 / 卷七三基条下九个直接 pair：

- 君基 × 天乙 / 地乙 / 直符；
- 臣基 × 天乙 / 地乙 / 直符；
- 民基 × 天乙 / 地乙 / 直符。

唯一 runtime：

`src/kintaiyi/three_bases_three_spirits_relations.py`

rule id：

`C90-THREE-BASES-THREE-SPIRITS`

不在 C82：

- 四神；
- 大游；
- 小游；
- 五福；
- 自动位置比较。

## 2. 为什么君基三条不能写成普通 omen 表

臣基、民基条基本直接给出“同宫则某灾应”。

君基三条不同，原文都是：

- 同宫；
- 再看人君采取何种治理 / 用兵行为；
- 合理则见吉；
- 失德则见灾。

因此 C90 对君基固定：

`structure="conditional_governance"`

并保留两支：

- `favorable_source_conduct`
- `adverse_source_conduct`

如果只给 same_palace=True，但没有选 conduct branch：

- 不输出单一吉凶；
- 两支条件原样返回；
- status 保持 conditional + pending。

## 3. 君基 + 天乙

有利行为稳定核心：

- 出符文；
- 降诏命；
- 练甲胄；
- 誓军旅；
- 征不道；
- 伐不义。

结果：

- 君国致祯祥。

不利行为：

- 好攻战；
- 轻百姓；
- 饰城郭；
- 侵边境。

结果：

- 不祥变异；
- 妖怪；
- 兵火之咎。

## 4. 君基 + 地乙

有利：

- 卑宫室；
- 去奢侈；
- 息土工；
- 安百姓；
- 务农桑；
- 劝稼穑。

结果：

- 德永昌；
- 地生祥瑞；
- 天下丰和；
- 景命惟新。

不利：

- 奢淫骄慢；
- 广营宫室；
- 缀饰珠玉；
- 妆丽过甚。

结果：

- 兵火丧亡；
- 五谷荒俭；
- 民生灾疾；
- 地生异类妖物。

## 5. 君基 + 直符

该段电子转录有少数字词不稳。

C90 只保留稳定条件核心。

有利核心：

- 贤佞分别；
- 宫人有序；
- 率由旧章；
- 敬重功勋；
- 殊别嫡庶。

结果：

- 君国升平；
- 嘉祥。

不利核心：

- 谗邪胜正；
- 广营宫室；
- 吏为苛酷；
- 百姓愁怨。

结果：

- 大旱灾伤；
- 火烧宫庙；
- 饥馑；
- 疾疫；
- 不利君王。

不稳定措辞不在 C90 擅自补字。

## 8. 显式关系契约

C90 固定：

- `auto_position_lookup_used=False`
- `auto_same_palace_inference_used=False`

位置来源：

- 三基位置 → C66；
- 天乙 / 地乙 / 直符位置 → C64。

但 C90 不调用它们。

调用方必须显式给：

`same_palace=True | False | None`

## 9. 直符 / 值符

canonical：

`直符`

旧“值符”默认拒绝。

仅显式 compatibility：

`allow_legacy_zhifu_alias=True`

才映射为直符。
