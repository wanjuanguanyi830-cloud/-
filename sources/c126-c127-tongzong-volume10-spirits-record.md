## C126 三旗行宫

### 太岁青龙旗

《统宗》卷十：

- 积年以纪法60去之；
- 再以小周12去之；
- 余1起子，顺十二辰；
- 一岁一迁；
- “从亥而子”说明周期边界为亥→子复始。

因此执行边界固定为：

- 余1 = 子
- …
- 余12/0 = 亥

### 太阴黑旗

直接文本：

- 积年 + 邦盈差25；
- 大周360；
- 小周36；
- 行邦率3；
- 起亥，逆十二辰；
- 三年一移，三十六年一周。

采用1基年段：

- 小周第1–3年 = 亥
- 第4–6年 = 戌
- …
- 第34–36年 = 子

不得使用0基 `remainder // 3` 把第3年提前移到下一宫。

### 害气赤旗

直接文本：

- 积年 + 邦盈差1；
- 大周40；
- 小周4；
- 起亥；
- 逆行四孟；
- 一年一移，四年一周。

执行次序：

`亥 → 申 → 巳 → 寅`

即余1=亥、余2=申、余3=巳、余4/0=寅。

### 三旗会合

卷十直接说：

- 二神会合：灾缓
- 三神会合：灾急

runtime 只判断三旗彼此同支。与太乙会合需要另有太乙位置输入，当前函数不会自动制造。

## C127 九宫贵神

### 直事神

卷十：

- 上元甲子积年先取周纪360；
- 周纪余 + 宫盈差3；
- 以小周9去之；
- 起一宫，逆行九宫。

神序：

1. 太乙
2. 摄提
3. 轩辕
4. 招摇
5. 天符
6. 青龙
7. 咸池
8. 太阴
9. 天乙

逆行直事序因此为：

`1太乙 → 9天乙 → 8太阴 → 7咸池 → 6青龙 → 5天符 → 4招摇 → 3轩辕 → 2摄提`

原书明确例：

> 小周余三，即得太阴。

此例作为硬回归。

### 钧宫飞行

原文令直事神钧入中宫，再令“相次之神飞出乾宫，依次顺行河图九宫”。

余3例直接给出：

- 太阴（8）入中
- 天乙（9）在乾
- 太乙（1）在兑
- 摄提（2）在艮
- 轩辕（3）在离
- 招摇（4）在坎
- 天符（5）在坤
- 青龙（6）在震
- 咸池（7）在巽

因此飞宫次序固定为：

`中 → 乾 → 兑 → 艮 → 离 → 坎 → 坤 → 震 → 巽`

神号从直事神的河图数按1→…→9循环递进。
