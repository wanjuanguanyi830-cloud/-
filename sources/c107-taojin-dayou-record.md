# C107-DAYOU-TAOJIN 《太乙淘金歌》大游所在宫

## 结论

《太乙淘金歌》大游应作为独立 source profile，不使用《太乙金镜式经》元法，也不使用《太乙统宗宝鉴》宫盈差。

执行参数：

- rule_id: `C107-DAYOU-TAOJIN`
- 起算：唐高宗永徽五年甲寅为第1年
- 起宫：七宫
- 周期：288年
- 每宫：36年
- 路径：7→6→4→3→2→1→9→8
- 方向：逆行
- 不入中五
- surplus: 0（因为本 profile 直接以自身纪元计数，不把它换算成其他来源历元）

## 《太乙淘金歌》直接见证

识典古籍《太乙淘金歌》当前转录明确保存：

- “大游太乙行八宫，七宫为首不虚中”
- “三六年移一位”
- “永徽五年甲寅岁，初起七宫为法例”
- 从永徽五年甲寅累计至开禧二年丙寅，共得553年
- 以288年周法推得“今在八宫住一十三年”

公开核对：

https://www.shidianguji.com/book/7504934605703610380/chapter/1lx5eg1yd22we

553年回归：

- 553 mod 288 = 265
- 前七宫各36年共252年
- 余13年
- 因此落路径第8位：八宫，第13年

与原例完全相合。

## 路径字形复核

《太乙淘金歌》当前 OCR 的歌句在“二”与“九”之间存在漏字现象，但后出的《古今图书集成·艺术典》明确抄作：

> 七六四三二一九八，此大游所行之序。

并说明“起自七宫”“三十六年移一宫”“二百八十八年一周”。

公开核对：

https://zh.wikisource.org/zh-hans/欽定古今圖書集成/博物彙編/藝術典/第687卷

因此执行路径取：

`(7, 6, 4, 3, 2, 1, 9, 8)`

## 与金镜、统宗的来源边界

《太乙金镜式经》与《太乙统宗宝鉴》现行 C107 profile 的路径均为：

`7→8→9→1→2→3→4→6`

淘金歌的逆序不能覆盖两者；反之，金镜4320元法与统宗+34宫盈差也不能移植到淘金歌。

软件调用必须显式选择 source profile。
