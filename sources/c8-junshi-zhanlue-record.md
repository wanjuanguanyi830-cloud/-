# C8 卷五 `junshi_zhanlue` 重构记录

## 目标

把旧式 `junshi_zhanlue` 从“把多卷、多术一次性揉成一个字典”改成明确的组合层。C8 不再复制八占公式，也不允许未校勘的跨卷规则互相修正。

参考旧实现：`kentang2017/kintaiyi`（仅参考，不作为真源）。旧实现中的同名函数混合了卷五、卷九、卷十七以及若干未分层的辅助判断，本记录据此定义隔离边界。

## 四层结构

### C8-L1 八占基础结果

直接调用 `eight_divinations.py`：

- D8-01 三才
- D8-02 长短
- D8-03 五音
- D8-04 孤单
- D8-05 内外
- D8-06 多少
- D8-07 阴阳厄会
- D8-08 数有所主

C8 不得重写这些公式。尤其：

- `数有所主` 必须是 D8-08，不是五音。
- 五音 D8-03 独立展示。
- 5 仅有地算（吏士）。
- 15/25/35 仅有天算+地算（将军+吏士），无人算/兵卒。
- 将居中五、三门五将等后续条件不得覆盖 D8-06 的基础多少结果。

### C8-L2 三门五将

当前只接收上游已经算出的“三门具/不具”“五将发/不发”事实并归一化。

本层 **不**：

- 从太乙宫自行重算三门；
- 从天目格局或将宫自行重算五将；
- 用八占长短、孤单、多少去反推三门五将。

原因：旧实现中的三门、五将计算尚需独立对原典和版本来源校勘，不能在 C8 组合层中把旧代码直接升格为 canonical。

### C8-L3 主客动静

只保留卷五“先后动静”的角色语义：

- 野战旗鼓相望：先动者为客，后应者为主。
- 安居之代：先举者为主，后应者为客。

三门五将不备时可给“固守倾向”，但本层不直接宣告胜负。

旧实现把“算长/算短、数值大小、三门五将”一起写入 `zhuke_xianhou` 并给出胜负结论；C8 将其拆开：

- 数值多少胜负仍属于 D8-06；
- 长短仍属于 D8-02；
- 主客动静只管角色/先后与行动姿态。

### C8-L4 将帅贤否

C8 只消费已校勘的将帅旺衰状态，不在这里计算季节旺衰。

当前保守映射：

- 旺、相：有气，可任；
- 囚、死：无气，不利；
- 休：原文归类待校，保持 pending；
- 未提供：not_computable。

禁止拿以下内容替代本层来源：

- 七术 Mode B 的将帅乘气；
- 大神火十二长生；
- 卷十七格局；
- 未校勘的“刑”关系。

## 默认排除的旧混合项

以下内容不进入 C8 默认主链：

1. **孤虚对照**：旧实现把卷五内外攻击与卷十七求索术合在一起。
2. **太乙助主客**：旧实现函数注释和判断同时援引卷五/卷九语义，须拆源后再定。
3. **辅相贤否**：应独立于将帅贤否，不能共享同一综合判断。
4. **诸将旺衰**：应由独立旺衰规则层提供事实，C8 只消费。
5. **郡国进贤、出师略地**：虽然同属卷五，但不属于军事胜负综合主链。

## 旧实现中确认不能继续沿用的混合

旧 `_calc_jianbei` 同时承担“长短”和“将吏兵备”，并通过字符串数字判断 `0/5/1` 以及 `n>=16` 直接推“俱备”。这与已经确认的 D8-01/D8-08 结构不一致，因此 C8 完全不调用此算法。

旧 `junshi_zhanlue["数有所主"]` 实际调用 `wuyin_from_calc`，属于明确的术类错接；C8 已拆为：

- `五音` → D8-03；
- `数有所主` → D8-08。

## Canonical / variant / pending 原则

- C8 canonical：层级结构、组合边界、D8 复用关系。
- source_variant：跨卷或不同版本的补充判法，不默认影响主结论。
- pending：三门公式、五将公式、将帅“休”态、太乙助主客跨卷语义等未校清部分。
