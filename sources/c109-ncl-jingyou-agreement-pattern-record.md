# C109 NCL-06604 与《景祐太乙福应经》一致读法簇

日期：2026-10-05

## 目标

C108 已建立四库、NCL 明钞、《景祐太乙福应经》的三见证机器矩阵。

C109 只记录一个文本现象：

NCL-06604 与《福应经》在多个实质规则点上出现相同读法。

这是一组 **agreement pattern**，不是抄本谱系结论。

## 当前三组明确一致

### J4M-06 陈兵向背

NCL 明钞：

- 1 -> 西北
- 2 -> 正南
- 3 -> 东北
- 4 -> 正东
- 6 -> 正西
- 7 -> 西南
- 8 -> 正北
- 9 -> 东南

《福应经》对应“释陈兵向背”保存相同的数值—方向骨架。

四库本则是 1/2/4/5/6/9，且结构更完整，另列战利、背地、阵形、旗色。

### J4M-09 天外地内

NCL：
- 地内 [1,8,3,4]
- 天外 [9,2,7,6]

《福应经》：
- 地内 [1,8,3,4]
- 天外 [9,2,7,6]

四库：
- 地内 [8,3,4]
- 天外 [9,2,7,6]

### J4M-11 风云飞鸟

NCL：
- 主人刑上来 -> 主人败
- 客刑上来 -> 客败

《福应经》：
- 主人刑上来 -> 主人败
- 客刑上来 -> 客败

四库当前读法：
- 主人形上来 -> 客败

这里不仅“形/刑”字形不同，胜负主体也不同，所以属于实质 event-verdict variant。

## 明确禁止的推论

C109 不允许从上述一致现象推出：

- NCL 明钞本抄自《福应经》；
- 《福应经》抄自 NCL；
- 二者必有同一直接祖本；
- 二者年代先后可由这三条决定；
- NCL 与《福应经》可以合并成同一个 source profile。

现阶段只能说：

**在 J4M-06、J4M-09、J4M-11 三个独立规则点上，NCL 明钞与《福应经》保存了相同或同构的实质读法，而四库本在这些点上存在差异。**

这对后续传本研究有价值，但不足以建立 stemma。

## C115 反例补充：J4M-08 是混合型读法

C109 曾明确要求：若后续出现反例，必须同时登记，避免只挑 NCL 与《福应经》一致项造成确认偏差。

C115 的 J4M-08 全文校勘正好提供了这种反例。

NCL 与四库一致的项目包括：
- 步兵地：车骑三不当一；
- 矛鋋地：弓弩三不当一；
- 士卒不习：百不当一。

但 NCL 的“将不习兵”却写：
- 五不当一，

这一数值又与《汉书》/《福应经》对应体系接近，而与四库 profile“十不当一”不同。

因此 NCL 不是简单“更接近《福应经》”或“更接近四库”的单线见证，而是至少在 J4M-08 中表现出混合型读法。

这进一步强化 C109 的原政策：文本一致只能逐项记录，不能直接转成 stemma。
