## 《太乙金镜式经》卷一：太岁

“推太岁所在法”：

1. 置上元甲子积年；
2. 以360去之；
3. 不尽再以60去之；
4. 命甲子算外；
5. 得太岁所在辰。

程序保存：

- `remainder_360`
- `remainder_60`
- `taisui_ganzhi`
- `taisui_branch`

## 0余数边界

这里不能把Python `% 60 == 0` 直接解释成甲子。

因为古法是1基“算外”序列：

- 1 -> 甲子；
- …
- 60 -> 癸亥；
- 61 -> 甲子。

故：

`r60 = n % 60 or 60`

360同理：

`r360 = n % 360 or 360`

这是本条的周末处理，不能推广为所有古法统一规则。

## 开元十二年锚点

《金镜》卷一：

上元甲子至唐开元十二年甲子积：

`1,937,281`

计算：

- 360余121；
- 60余1；
- 太岁甲子。

与原文“开元十二年甲子”自校一致。

## 《太乙统宗宝鉴》卷一：五元七十二局

360周再分五元，每元72局：

1. 甲子元；
2. 丙子元；
3. 戊子元；
4. 庚子元；
5. 壬子元。

边界：

- 甲子元：1..72；
- 丙子元：73..144；
- 戊子元：145..216；
- 庚子元：217..288；
- 壬子元：289..360。

因此：

`local_ju = ((r360 - 1) % 72) + 1`

该 `local_ju` 供G2太乙24周与G3文昌18周消费。

## 72局辅助

同一局横跨五元五个干支年，但年支相同，因此回归测试可用：

`branch = 十二支[(ju-1) % 12]`

这只用于72局立成回归；正式业务链仍应由积年先求完整六十甲子太岁。
