# 术语目录

本目录集中定义术语词形与坐标。

本次新增坐标表不代表已导入仓库外的完整术语总库；本地旧术语快照尚未迁移，避免与本次规则整理混成未核对的数据导入。

- [`palace_coordinates.json`](palace_coordinates.json)：十二运行位（`running_palace`）和九宫（`nine_palace`）分立的映射。
- [`sixteen_spirits.json`](sixteen_spirits.json)：十六神、地支／间神写法及九宫映射；“大旲”作为原文／OCR别名指向规范名“大炅”。

运行规则引用这些坐标，但不以运行位编号替代九宫编号。
