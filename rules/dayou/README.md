# 大游太乙

- [`dayou.json`](dayou.json)：大游太乙九宫运行顺序及周元参数。
- [`tianmu.json`](tianmu.json)：大游天目正式采用的18步路径与216／72／18待校勘记录。

大游的位置字段属于九宫。大游天目的18项是含重留位置的行进路径；现有材料不足以把每步解释成固定年数，故不填造 `years_per_position`。

天目取步按原聊天登记的《金镜》推法：先以72求余，再以18求余，0余数归末位。采用理由及开元十二年积年校验见 [`../../sources/base-motion-rule-record.md`](../../sources/base-motion-rule-record.md)。
