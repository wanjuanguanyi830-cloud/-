# 《太乙金镜式经》格局引擎

实现文件：[`engine.py`](engine.py)。主算法规则集为 `jinjing`，当前版本 `jinjing-geju-1.0.0`，规则来源为《太乙金镜式经》卷三；值事门周期见 [`../eight_door.py`](../eight_door.py)，来源为卷四。

## 空间坐标

十六神环：`子、丑、艮、寅、卯、辰、巽、巳、午、未、坤、申、酉、戌、乾、亥`。宫中心和间神保留为不同环位。

```python
PALACE_RING = (8, 3, 4, 9, 2, 7, 6, 1)
```

太乙四宫时，寅是内辰、卯为正宫；太乙八宫时，三宫为外宫。

## 格局规则

- **掩、击、格**：由始击判定；始击同正宫为掩，前／后辰或宫为击，对宫为格。
- **囚、迫、对**：由文昌判定；精确同正宫为囚，前／后辰或宫为迫，对宫为对。始击与定目都不参与迫。
- **将类囚、迫、关、格**：四将与太乙同宫为囚、前／后邻宫为迫，四将彼此同宫为关；客大、客参在太乙对宫为格。
- **提挟**：按八宫环通用枚举主体和目标。太乙、四将构成夹持点；主客目只在正宫目标位置参与普通提挟，间神由挟闭判断。
- **挟闭**：文昌和始击都在间神，且太乙、主将、客将共同在十六神环上夹持二目。单独输出，不并入提挟。
- **执提、提格**：只由值事开门或生门触发；同太乙宫为执提、在对宫为提格。积年输入按240年周期确定值事门。
- **四郭固、四郭杜**：由基本格局和将位关系组成的复合格局。机器主字段使用“四郭杜”；“四郭社”只出现在异文记录。

## 接口

```python
from rules.jinjing.geju import GejuContext, analyze_geju, to_legacy_dict

detail = analyze_geju(context)
legacy = to_legacy_dict(detail)
```

`analyze_geju()` 返回规则集、版本、来源、盘面快照和逐条事件；每条事件包含主体、目标、位置、成格依据、断语及出处。`to_legacy_dict()` 返回旧式“格局键→断语”字典。`TaiyiGejuMixin` 提供 `shi_geju(ji_style, taiyi_acumyear)` 与 `shi_geju_detail(...)` 两个兼容入口；宿主类实现 `_jinjing_geju_context()` 即可接入。此规则库不导入或依赖参考项目的 `Taiyi` 类。

## 研究边界

`kintaiyi` 的 `skyeyes_summary` 和历史局例只作为固定版本的差异与回归样本。它们不修改《金镜》规则。输入中的文昌／始击须先规范到十六神位置；未归一化的旧称名会明确报错。
