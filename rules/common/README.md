# 共享空间与五行规则

`taiyi_space.py` 为有来源限制的太乙算法提供统一坐标和基础五行状态。该层只负责坐标、宫位五行与状态，不负责某一术的吉凶断语。

## 十六位、十六神与九宫

十六位按环序保存：

```text
子 → 丑 → 艮 → 寅 → 卯 → 辰 → 巽 → 巳
  → 午 → 未 → 坤 → 申 → 酉 → 戌 → 乾 → 亥 →（回到子）
```

八个代表点与八宫对应：

| 九宫 | 代表点 | 五行 |
|---:|---|---|
| 1 | 乾 | 金 |
| 2 | 午 | 火 |
| 3 | 艮 | 土 |
| 4 | 卯 | 木 |
| 5 | 中宫 | 土 |
| 6 | 酉 | 金 |
| 7 | 坤 | 土 |
| 8 | 子 | 水 |
| 9 | 巽 | 木 |

完整十六位到九宫映射见 `POSITION_TO_PALACE`。十二支点按其太乙宫位取五行；不可在此层改用普通地支五行表。五宫保留九宫土性，但当前没有对应的十六位代表点；需要十六位落点的算法会返回不可计算状态。

位置与十六神名的对应表保留不同文字形式。`巽`位在记录中兼收“大炅”“太炅”，调用结果以位置坐标为准，不替底本选字。

## 吕申加位与大神落点

`dashen_from_lushen(anchor)` 接受一个十六位或一个非中宫九宫数。九宫数先转为代表点，再沿十六位环顺推四位，返回大神落点。例：

```text
子 → 卯
卯 → 午
午 → 酉
酉 → 子
九宫3（艮）→ 巽
九宫7（坤）→ 乾
```

该函数不推算日期干支，也不将破年支转换为公历／干支年月日。

## 五行状态

`qi_state(subject, environment)` 的主客方向固定为“所占对象在落宫环境中的状态”：

| 关系 | 五态 |
|---|---|
| 同类 | 旺 |
| 环境生对象 | 相 |
| 对象生环境 | 休 |
| 对象克环境 | 囚 |
| 环境克对象 | 死 |

同一五态函数由七术按术义选择主体：大神火自身状态以火为对象；雷公入水、白龙得云、回军无言以将帅宫五行为对象。

## 大神火的十二阶段

大神火按十二阶段顺序记录：寅长生、卯沐浴、辰冠带、巳临官、午帝旺、未衰、申病、酉死、戌墓、亥绝、子胎、丑养。四个卦位艮、巽、坤、乾没有地支阶段，返回 `None`。规范名固定为**帝旺**；“帝王”仅保留为底本／转录异文。

阶段和五态是两个并列字段，不互相覆盖。例如未位可同时记录五态“休”和阶段“衰”。哪个术取用阶段，在哪个阶段作何断语，由术规则单独决定。
