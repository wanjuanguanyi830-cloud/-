# 七术与八占 v1

规则集编号：`taiyi-war-seven-v1` 与 `taiyi-war-eight-v1`，版本均为 `1.0.0`。七术按《四库全书》本卷六现有整理，八占综合本轮确认的卷六规则与《统宗宝鉴》补充。它们与 `rules/jinjing/` 并列；不会覆盖《太乙金镜式经》的格局规则。

## 公共依赖

空间、吕申加位、五行生克、旺相休囚死和大神火十二阶段统一在 [`../common/taiyi_space.py`](../common/taiyi_space.py)。复用十六位坐标的金镜规则仍保留既有 `rules.jinjing.geju` 导入接口；本次不改该模块。

```python
from rules.common.taiyi_space import dashen_from_lushen, qi_state
from rules.warfare_v1 import linjin_ask_way, three_talent
```

所有函数输出可复核中间量。落宫与五行状态无法由输入确定时返回 `None` 或 `可计算=False`，不补推干支、应期、刑表或古籍未给出的平局结论。

## 八占

| 编号 | 占法 | 已确认规则 |
|---|---|---|
| D8-01 | 三才 | 十→天、五→地、一→人；分别报无天／无地／无人及天象／地变／人事类。结构俱备不等同于古法所举的典型三才足数 |
| D8-02 | 长短 | 11及以上为长，10及以下为短；长宜缓、宜深入，短宜急、宜浅入 |
| D8-03 | 五音 | 个位映射1–10成宫、徵、羽、商、角及正音／比音、五行和所主；个位0按10处理 |
| D8-04 | 孤单 | 个位1、3、7、9单阳；2、4、6、8单阴；5、0不取单阴阳。十位10／30孤阳，20／40孤阴；同阴阳相合成重阳／重阴 |
| D8-05 | 内外 | 固定神名分区：阴德至太阳为内，大炅至阴主为外。天目在内则内虚、攻外；在外则外孤、攻内；不依太乙宫重新划分 |
| D8-06 | 多少 | 客算大于主算，客多临少，主败；客算小于主算，客少临多，主胜；同数只报告同数，古法断语留空 |
| D8-07 | 阴阳厄会 | 太乙阳宫8、3、4、9配奇数为重阳厄火；阴宫2、7、6、1配偶数为重阴厄水；未成重者不添灾类 |
| D8-08 | 所主 | 与三才共享十／五／一分解；对应将军／吏士／兵卒，不调用五音表 |

十／五／一公共分解为 `有十 = n >= 10`、`有五 = n % 10 >= 5`、`有一 = n % 10 != 0`。古书“三才”中“十、二十、三十、四十为无人”的断句采用十位数理解。典型三才足数只记录已列举的16–19、26–29、36–39，不把15、25等自动扩为同一古法类别。
