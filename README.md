# 太乙术语与基础运行规则备份

本仓库整理太乙术语、分层规则、来源依据、版本异文与可复核样例。术语释义、古籍原文、项目采用规则与代码计算彼此分层；不得仅凭同名词条推导公式。九宫数、十二运行位、地支等不同坐标各自建模；原典版本判断、用户已确认的整理规则和旧代码实现分别注明。

## 目录

- [`terminology/`](terminology/)：运行位、九宫和十六神的术语与坐标表。
- [`rules/base_motion/`](rules/base_motion/)：三基、五福与四太乙基础运行规则。
- [`rules/dayou/`](rules/dayou/)：大游太乙和大游天目规则及待校勘项。
- [`rules/xiaoyou/`](rules/xiaoyou/)：小游太乙；轨运入卦另立记录。
- [`rules/jinjing/`](rules/jinjing/)：《太乙金镜式经》既有格局规则。
- [`sources/`](sources/)：来源层级、出处记录和异文说明。
- [`tests/`](tests/)：固定边界样例和回归测试。
- [`CHANGELOG.md`](CHANGELOG.md)：批次变更摘要。
- [`changelog/`](changelog/)：按批次保存的详细变更记录。

## 规则采用原则

《太乙金镜式经》格局规则以该书卷三为主来源，八门值事周期采用卷四；相异文本作为来源说明与对照记录，不并入《金镜》规则。

本轮新增的基础运行规则以用户已确认的整理结果为 canonical 输入。它们不等同于本仓库已独立完成原典版本校勘；明代本、四库本及其他版本的书目、卷页定位仍在来源记录中追补。`kentang2017/kintaiyi` 仅作固定提交参考实现与历史样本来源，不是本仓库的写入目标，也不能覆盖相应原典或已采用规则。

## 验证

Python 3.10+ 并安装 pytest 后，从仓库根目录运行：

```powershell
python -m pytest
```

基础运行边界测试验证结构化数据按已记录的起点、步长和周期工作；测试通过不代替原典版本校勘。完整《金镜》规则测试还会检查参考局例、旧接口适配和历史差异报告。
